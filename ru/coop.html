Мультиплеер

Гайд по коопу

DragonSword: Awakening поддерживает ограниченный кооп через Охоты (2 игрока) и Рейды (3 игрока). Нет коопа в открытом мире или сюжете. Присоединяйтесь через код приглашения — без матчмейкинга, без списка друзей. Каждый игрок приносит свою собственную полную партию из 3 героев.

📖 Время чтения: ~5 мин 👥 Охоты 2И / Рейды 3И 🔗 Только код приглашения
⚡ Быстрый ответ

Только Охоты (2И) и Рейды (3И) поддерживают кооп. Нет открытого мира, нет сюжета, нет мультиплеера Башни испытаний. Каждая сессия требует создания лобби и обмена кодом приглашения. Нет матчмейкинга — только друзья через код. Каждый игрок использует свою собственную партию из 3 героев. Нет быстрого повтора — нужно создавать лобби заново после каждого забега. Игра в основном является одиночным опытом.

✅ Контент с поддержкой коопа

Режим Макс. игроков Описание
Охоты (Покорение) 2 игрока Бои с боссами на закрытой арене. Каждый игрок приносит свою собственную партию из 3 героев.
Рейды 3 игрока Инстансовый контент высокой сложности. Можно проходить соло или с до 2 друзьями.

❌ Контент без коопа

  • Основной сюжет — Кампания только для одиночной игры
  • Исследование открытого мира — Нельзя исследовать карту вместе
  • Башня испытаний — Вызов эндгейма только соло
  • Общее исследование поля — Нет коопа в открытом мире
  • Побочные квесты — Все квесты одиночные
  • PvP — Режима игрок против игрока не существует

🎮 Как играть в коопе

  1. Хост создаёт лобби — Откройте меню мультиплеера и создайте новую сессию
  2. Выберите контент и сложность — Только хост может выбирать Охоту/Рейд и уровень сложности
  3. Сгенерируйте код приглашения — Лобби создаёт уникальный код приглашения
  4. Поделитесь кодом — Отправьте код приглашения вашему другу(друзьям)
  5. Друзья вводят код — Друзья вводят код приглашения, чтобы присоединиться к лобби
  6. Начните бой — Когда все готовы, начните встречу
  7. Лобби расформировывается после — Нужно создавать всё лобби заново для следующего забега

⚙️ Механики коопа

🔗

Система кодов приглашения

Присоединяйтесь через уникальный код приглашения. Список друзей Steam не требуется. Нет матчмейкинга — вы можете играть только с людьми, у которых есть ваш код.

👥

Каждый игрок = Полная партия

Каждый игрок приносит свою собственную полную партию из 3 героев. В 3-игроковом рейде это 9 героев на поле одновременно.

🏠

Хост контролирует всё

Только хост лобби выбирает контент и сложность. Если настройки неверны, всё лобби нужно расформировать и создать заново.

🔄

Нет быстрого повтора

После завершения Охоты или Рейда лобби автоматически расформировывается. Вам нужно пройти полный процесс создания лобби заново для следующего забега.

👍 Преимущества коопа

  • Лёгкий контент высокой сложности — Рейды и Охоты высокого тира гораздо проще проходить с друзьями
  • Социальный опыт — Сражайтесь с боссами вместе и разделяйте вызов
  • Полная партия на игрока — У каждого игрока есть 3 героя, создавая богатые тактические комбинации
  • Простая система приглашений — Список друзей не нужен, просто поделитесь кодом
  • Рейды можно проходить соло или в коопе — Выбирайте в зависимости от ваших предпочтений и силы партии

👎 Ограничения и проблемы

  • Очень ограниченный контент — Только Охоты и Рейды. Нет коопа в открытом мире вообще
  • Громоздкий рабочий процесс — Нужно создавать лобби заново после каждого забега, нет быстрого повтора
  • Настройки только у хоста — Только хост выбирает контент/сложность; неверная настройка означает полный перезапуск
  • Нет матчмейкинга — Нельзя играть со случайными игроками, только друзья
  • Прогресс гостя неясен — Сохраняется ли прогресс гостя, не полностью задокументировано
  • Условия разблокировки неясны — Точное время разблокировки мультиплеера плохо задокументировано
  • Конфликты модов — Моды могут препятствовать онлайн-игре (обоим игрокам нужны идентичные моды или патчи-обходы)

💡 Советы по коопу

1

Координируйте партии

Обсудите с друзьями состав команды заранее. Покройте разные элементы и роли (DPS, саппорт, разрушитель) для максимальной эффективности.

2

Хост планирует заранее

Будучи хостом, точно знайте, какую Охоту/Рейд и сложность вы хотите перед созданием лобби. Неверные настройки = полный перезапуск.

3

Берите еду с баффами

Каждый игрок должен съесть своё собственное Баффовое рагу Варки перед присоединением. Баффы ATK/Крит на 15 минут складываются по всей партии.

4

Используйте только для эндгейма

Кооп действительно полезен только для Рейдов и Охот высокой сложности. Сюжет и открытый мир разработаны для одиночной игры.

🔮 Будущие обновления коопа

На основе роадмапа разработчика, будущие обновления могут добавить:

  • Больше активностей с поддержкой коопа
  • Система Измерения Разлома (измеренческие разломы)
  • Дополнительные бесплатные герои
  • Личные / индивидуальные квесты

Примечание: Игра выпущена 23 июля 2026. Функциональность коопа, вероятно, будет расширяться с будущими обновлениями.
