Theresia — Инквизитор

Одна из десяти еретиков-инквизиторов с правом казни. Самая самодостаточная DPS с Кровотечением и Оглушением в игре — накладывает оба недуга сама, без партнёра по подготовке.

Два булава
Черта Амплитуда
Кровотечение / Оглушение
Магазин обмена
⚡ Быстрый ответ

Theresia — лучший агрессивный керри в игре. Она накладывает и Кровотечение, И Оглушение сама, что делает её самым простым героем для построения команды вокруг. Основной цикл: Consecration (Кровотечение) → Celestial Verdict (Оглушение) → переключиться на Roxy для взрыва. Лучшая команда: Theresia + Roxy + Lute.

🔄 Основной цикл комбо

Подготовка Theresia одним героем

В отличие от большинства героев, Theresia не нуждается в партнёре для подготовки своих недугов. Она делает всё сама:

  1. Consecration — Наложите Кровотечение, продлите цепочку атак
  2. Celestial Verdict — Удар для Оглушения, открывает сигнальное окно
  3. Переключитесь на союзника — Roxy или другой герой запускает их сигнальный навык на оглушённом враге
  4. Переключитесь обратно — Продолжайте давление с Divine Arc на оглушённых целях
💡 Ключевое понимание

Поскольку Theresia накладывает и Кровотечение, и Оглушение сама, она является самым гибким якорем команды в игре. Любой герой, реагирующий на любой из этих недугов, работает с ней.

🛡️ Лучший билд (консенсус эндгейма)

Эксклюзивная кармаМилосердный смертный приговор
Наборы снаряжения3 Разрушитель руин + 2 Святой Арбитр
Основные характеристикиУсиление ATK → Шанс крит. попадания → Крит. урон
ПодхарактеристикиДополнительная мощь > Усиление ATK > Игнорирование DEF
РунаРешимость (или 5x Усиление для макс. крит. урона)
Целевые характеристики~80% крит. рейт / ~150% крит. урон

Почему этот билд

  • 3 шт. Разрушитель руин — Игнорирование DEF на сигнальных навыках (10с, 20% пробития DEF). Критически важно для урона по боссам.
  • 2 шт. Святой Арбитр — +15% урона по оглушённым врагам. Идеально соответствует стилю игры Theresia с фокусом на Оглушение.
  • Решимость — Надёжное усиление урона. Замените на Усиление x5, если хотите рискнуть ради макс. крит. урона.

👹 Цикл боя с боссом

  1. Откройте с Celestial Verdict Theresia для наложения Оглушения
  2. Как только враг оглушён, переключитесь на Roxy для запуска её сигнального навыка
  3. Продолжайте выводить урон через Roxy, пока цель под контролем
  4. Используйте третьего героя (Lute для лечения, Castella для дополнительного Оглушения) для завершения цикла
  5. Переключитесь обратно на Theresia и повторите — Consecration → Celestial Verdict → взрыв Divine Arc

🎮 Боевые советы

1

Самодостаточная подготовка

Theresia не нуждается в союзниках для подготовки недугов. Она накладывает Кровотечение + Оглушение сама — единственный герой, который может делать оба надёжно.

2

Сначала Consecration

Всегда открывайте с Consecration для наложения Кровотечения и продления цепочки атак перед использованием Celestial Verdict для Оглушения.

3

Divine Arc = Взрыв

Divine Arc по оглушённым врагам — ваш основной источник урона. Один из самых высоких взрывных навыков во всей игре.

4

Holy Rise для Воздуха

Holy Rise подбрасывает кровоточащих врагов в Воздух. Используйте это для интеграции Theresia в составы команд Воздуха.

5

Широкий радиус булав

Два булава имеют более широкий радиус, чем большинство ближнего оружия. Вы редко будете промахиваться по группам, что делает её отличной для зачистки мобов.

6

Сначала пробудите

При пробуждении 6★ разблокируются пассивки и усиленные навыки. Только тогда характеристика крит. рейта стоит инвестиций.

⚠️ Распространённые ошибки

  • Неправильная элементальная карма — Всегда используйте её эксклюзивную карму (Милосердный смертный приговор), а не универсальное оружие
  • 5 штук одного набора — Никогда не используйте 5 одного набора. Смешивание 3+2 (Разрушитель руин + Святой Арбитр) всегда лучше
  • Игнорирование игнорирования DEF — Игнорирование DEF от Разрушителя руин критически важно для урона по боссам. Не пропускайте его
  • Мышление чистого DPS — Сила Theresia исходит от недугов, а не от сырых атак. Всегда накладывайте Кровотечение/Оглушение
  • Ранняя инвестиция в эксклюзивную карму — Подождите, пока вы не уверены, что Theresia — ваш основной DPS, перед фармом её эксклюзивных материалов
