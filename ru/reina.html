Королевство Орбис · S тир

Reina — Ветер, что защищает

Основной подбрасыватель в воздух в игре и один из сильнейших персонажей жонглирования. Держит врагов беспомощными в воздухе, ограничивая их возможности контратак. Высокая мобильность со спринтом + отдельным уклонением.

Меч Gale
Черта Gale
Воздух / Кровотечение
Командир 8-го ордена
⚡ Быстрый ответ

Reina — лучший подбрасыватель в воздух и ядро каждой команды жонглирования. Подбрасывайте врагов с Rising Cutter или Wind Slayer, продлевайте с Wind Grab и завершайте наземным шлёпаном Castella. Лучшая команда: Reina + Castella + Lute. Билд: 3 Разрушитель руин + 2 Лазурный Gale. Воздух — одна из сильнейших механик, потому что подброшенные враги не могут контратаковать.

🪽 Последовательность воздушного комбо

Reina + Castella + Lute — Полный цикл жонглирования

  1. Откройте с Reina — Используйте Rising Cutter или Wind Slayer для подбрасывания цели
  2. Сразу Tempest — Пока враг начинает подниматься, выполните сигнальный навык Reina Tempest
  3. Переключитесь на Lute — Активируйте сигнальный навык Lute для продления длительности Воздуха
  4. Перейдите к Castella — Шлёпните цель о землю для массивного урона
  5. Повторите — Зациклите для поддержания контроля окна Воздуха
💡 Почему Воздух сломан

Воздух — одна из сильнейших механик в игре, потому что враги, подвешенные в воздухе, имеют ограниченные возможности контратак. Они не могут блокировать, не могут запустить Суперброню и не могут использовать специальные атаки. Хорошо выполненное жонглирование = бесплатное окно урона.

💨 Мобильность: «Мобильный мост»

Reina имеет уникальные опции мобильности, которые делают её «мостом» любой команды:

  • Движение в стиле спринта — Длинный рывок для восстановления дистанции
  • Отдельное уклонение — Короткая эвазия для решительных атак
  • Две опции перепозиционирования — Используйте длинный спринт для восстановления дистанции, сохраняйте короткое уклонение для следующей решительной атаки

✅ Преимущества

🪽

Ядро Воздуха S тира

Основной подбрасыватель в воздух. Необходима для каждого состава команды жонглирования.

⚡

Двойные подбрасыватели

И Rising Cutter, и Wind Slayer накладывают Воздух. Гибкие открыватели комбо для любой ситуации.

🔄

Двойные сигнальные навыки

Tempest (триггер Оглушения) и Wind Grab (триггер Воздуха). Реагирует на два разных недуга.

💨

Высокая мобильность

Спринт + отдельное уклонение = две опции перепозиционирования. Лучший набор мобильности в игре.

🎪

Лучший жонглёр

Держит врагов в воздухе, ограничивая их контратаку. Создаёт более длинные цепочки атак в сложных столкновениях.

🔧

Универсальное соответствие

Может встать в многие команды как третий участник. Работает с архетипами Огня, Льда, Кровотечения и Яда.

❌ Недостатки

  • Зависимость от Воздуха — Против врагов с Супербронёй Воздух не срабатывает и Reina теряет значительную ценность
  • Нуждается в союзниках — Лучшая производительность требует завершителей вроде Castella для использования окон Воздуха
  • Риск ближнего боя — Несмотря на высокую мобильность, она всё ещё ближний боец и может быть наказана
  • Кровотечение вторично — Кровотечение Tempest — бонусный эффект, а не её основной источник урона
  • Требуется исполнение — Нуждается в точном тайминге Воздуха и ритме переключений для максимизации длительности жонглирования

🎮 Боевые советы

  1. Открывайте с подбрасывателей — Всегда начинайте с Rising Cutter или Wind Slayer для отправки врагов в воздух
  2. Tempest на Оглушении — Когда союзники накладывают Оглушение, переключитесь на Reina и запустите Tempest для Кровотечения
  3. Wind Grab для продления — Используйте Wind Grab сразу после подбрасывания, чтобы держать врагов в воздухе дольше
  4. Используйте оба уклонения — Длинный спринт восстанавливает дистанцию, короткое уклонение для разрывов атак. Не тратьте ни одно впустую
  5. Сочетайте с Castella — Перед окончанием окна Воздуха переключитесь на Castella для завершителя наземного шлёпана
  6. Lute продлевает цепи — В командах Воздуха Lute может дополнительно продлить длительность Воздуха
  7. Держите их в воздухе — Враги в состоянии Воздуха имеют ограниченную контратаку. Жонглирование = безопасность.

⚠️ Распространённые ошибки

❌

Принуждение Воздуха к Суперброне

Против врагов с Супербронёй Воздух неэффективен. Переключитесь на другую стратегию или возьмите разрушителей брони.

❌

Не переключаться после подбрасывания

Подбрасывание и затем пребывание на Reina тратит окно урона Воздуха. Переключайтесь на завершителей немедленно.

❌

Игнорирование Кровотечения Tempest

Кровотечение Tempest — бесплатный дополнительный источник урона. Всегда используйте его, когда наложено Оглушение.

❌

Трата двойных уклонений впустую

Мобильность Reina — её самое большое преимущество. Используйте обе опции уклонения стратегически.

❌

Игра как дистанционный

Reina — ближний воздушный персонаж. Если хотите дистанционный бой, выберите Cerese или Othello.

❌

Без набора Лазурный Gale

2 шт. Лазурный Gale критически важны для урона Воздуха. Не пропускайте их.
