Калиэн — Маг Духов

Маг духов, сражающаяся вместе с огненным лисом Сур. Калиэн быстро накладывает Горение клонами лисы и наносит взрывной урон с Оглушением через Захват Лисы и Финал.

⚡ Краткий ответ

Калиэн — DPS Горения A-ранга, управляющая полем боя через духа лисы Сур и армию клонов. Она быстро накладывает Горение по площади, затем наносит большой урон с Оглушением через Захват Лисы и Финал. Лучшая команда: Калсион + Ария для мета-команды Горение/Воздух. Снаряжение: 3 Пылающее Пламя + 2 Разрушителя, приоритет: Атака, Крит. шанс, Крит. урон.

🔥 Стиль боя

Набор Калиэн сосредоточен на контроле целей оглушением, пока огненный урон Сура наносится под ним. Её роль в трёхшаговой системе комбо — настаивать оглушение на цели через активные навыки, затем добить своим сигнальным навыком или смениться, чтобы союзник провёл сигнальный навык в окно оглушения.

Сур — это лисий дух, наделённый силой огня. Калиэн может призывать клонов-лис, которые автономно атакуют и накладывают горение по большой площади, что делает её превосходной в зачистке мобов и поддержании давления на элитные группы.

⚔️ Лучшая сборка

Сборка на горение (рекомендуется)

Комплекты

3 части Пылающего пламени + 2 части Разрушителя руин (обратный порядок тоже работает)

Пылающее пламя усиливает огненный урон и мощь горения. Разрушитель руин даёт игнорирование защиты для более сильного бурста в окно Финала.

Ария + Калиэн + Кальсион — цикл горения/подброса

  1. Ария накладывает горение И подброс одновременно — лучший активатор для этого состава
  2. Калиэн выпускает клонов-лис для быстрого настаивания горения по площади
  3. Калиэн использует Лисий захват для бурста горящей цели и оглушения
  4. Кальсион добивает усиленным Пламенем оружия уроном под горением + подбросом
  5. Лис Калиэн наносит автономный урон и оглушение между сменами

✅ Сильные стороны

🔥

Отличное давление горения

Клоны-лисы накладывают горение по большим площадям, облегчая поддержание периодического урона на группах.

💥

Зачистка AoE

Превосходно зачищает мобов и элитные группы эффектными атаками по площади.

⚡

Оглушение

Финал накладывает и горение, и оглушение — надёжный контроль вместе с большим уроном.

🦊

Автономный урон

Сур и клоны-лисы продолжают сражаться, пока вы переключаетесь на других героев.

❌ Слабые стороны

  • Зависит от позиции — большая часть урона зависит от размещения духа-лиса и таймингов
  • Подвижные враги — быстрые боссы могут покинуть зону атак лис, снижая бурст
  • Требуется подготовка — нужны активаторы горения (особенно Ария) для максимального урона
  • Не соло-керри — раскрывается в команде горения, менее эффективна в одиночку

🎮 Боевые советы

  1. Сначала клоны — выпустите клонов перед Лисьим захватом, чтобы горение уже настакалось
  2. Тайминг Финала с оглушением — используйте Финал, когда цель окружена клонами для максимума горения + оглушения
  3. Смена после оглушения — после оглушения Финалом переключитесь на Кальсиона или Арию для цепочки сигнальных навыков
  4. Позиция для групп — клоны блистают против групп; бои с одной целью снижают её ценность
  5. Контроль стаков горения — обновляйте горение клонами до истечения для постоянного урона
