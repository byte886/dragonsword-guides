Гайд по эндгейму

После сюжета начинается настоящая игра: Башня испытаний, Охоты и Рейды Ур90, вознесение Эксклюзивной Кармы, идеальная перековка снаряжения и 100% коллекция. Создайте ежедневную/еженедельную рутину для стабильного прогресса к мин-максимизированным героям.

📖 Время чтения: ~7 мин 🏆 7 активностей эндгейма ⏱️ 100+ часов
⚡ Быстрый ответ

Эндгейм = Башня испытаний (3 башни, уникальные награды Кармы) + Охоты/Рейды Ур90 + мин-максинг + 100% коллекция. Ежедневно: 3 Мировых босса (105 медалей) + ежедневные задания + валютные подземелья. Еженедельно: Рейды высокого тира + Охоты + прогресс Башни. Тратьте Медали обмена на Эмблемы (самый редкий ресурс, нужен для прорыва Ур60-70). Общее время игры: 150-200 часов для полного завершения.

🏆 7 основных активностей эндгейма

1. Башня испытаний (试炼之塔)

  • Местоположение: Гора Небесного шпиля
  • Текущий главный вызов эндгейма
  • Прохождение разблокирует уникальную Карму (карты оружия)
  • Основной поздний источник Осколков памяти
  • Источник Вихревых мыслей (для крафта Эксклюзивной Кармы)
  • Есть 3 башни для завоевания

2. Рейды высокой сложности (鏖战副本)

  • Разблокируются на Ур50, макс. сложность Ур90
  • Дропают Руны и материалы высокого тира
  • Ур62+ гарантирует SSR руны за прохождение
  • Долгосрочный лучший источник в слоте для бесплатных игроков
  • До 3-игрокового коопа

3. Охоты (讨伐/狩猎)

  • Мировые боссы и элитные монстры
  • Макс. сложность Ур90
  • Дропают Запись битвы (материал для улучшения навыков)
  • Дропают карты Кармы и дубликаты
  • Ежедневное обновление — фармите каждый день

4. Мировые боссы (世界Boss)

  • Разбросаны по областям открытого мира
  • Ежедневное возрождение
  • Самый надёжный источник дублей Базовой Кармы
  • Дропают Песочные часы и Медали обмена
  • 3 лёгких Мировых босса = 105 Медалей обмена/день
  • Выбирайте боссов, соответствующих элементу вашего основного DPS

5. Мин-максинг (极致数值优化)

  • Все 19 героев на макс. уровне, макс. прорыве
  • Вся Эксклюзивная Карма получена и вознесена до Ранга VI
  • Снаряжение 5 звёзд +15 с идеальными перекованными подхарактеристиками
  • Оптимальные конфигурации рун
  • Все навыки на максимуме

6. Коллекция и завершение (收集与完成度)

  • Журнал приключений: 149 записей, 5 глав
  • Достижения: всего 103, 5 категорий
  • Система титулов
  • 100% исследование карты
  • Коллекция фамильяров: всего 29
  • Кулинарные рецепты: 73 стандартных блюда

7. Оставшиеся побочные квесты

  • Незавершённый побочный контент после прохождения сюжета
  • Квесты героев (миссии, специфичные для персонажей)
  • Региональные задания

📅 Ежедневная и еженедельная рутина

Ежедневные задачи

  1. Победите 3 лёгких Мировых босса → 105 Медалей обмена
  2. Выполните ежедневные поручения
  3. Пройдите валютные подземелья (золото, руда, книги опыта)
  4. Проверьте Внезапные миссии для Осколков священного света (материал для Пробуждения)

Еженедельные задачи

  1. Рейды высокой сложности (общий еженедельный лимит наград)
  2. Охоты высокой сложности
  3. Прогресс в Башне испытаний
  4. Проверьте события с еженедельным сбросом

Долгосрочные цели

  1. Все герои на макс. уровне + макс. прорыве
  2. Идеальное снаряжение и руны для основной команды
  3. Вся Эксклюзивная Карма получена
  4. 100% достижений
  5. 100% исследование карты
  6. 100% Журнал приключений

⚠️ Критический совет по ресурсам

Эмблемы — самый редкий ресурс эндгейма. Они дропают только случайно из редких сундуков без надёжного метода фарма (кроме Обмена). Героям нужно большое количество для прорыва Ур60-70. Тратьте ваши Медали обмена на Эмблемы в первую очередь — это главный узкий место прогресса №1.

💡 Профессиональные советы по эндгейму

1

Медали → Эмблемы

Всегда тратьте Медали обмена на Эмблемы. Это самый редкий ресурс и главный узкий место прогресса для героев Ур60-70.

2

3 Мировых босса ежедневно

Три лёгких Мировых босса дают 105 медалей/день. Это ваш самый надёжный ежедневный доход — никогда не пропускайте.

3

Фокус на 1-2 DPS

Не распыляйте ресурсы. Выберите 1-2 основных DPS героев и максимизируйте их перед инвестициями в других.

4

Сначала Башня

Приоритизируйте прогресс Башни испытаний. Это источник Осколков памяти и Вихревых мыслей для Эксклюзивной Кармы.

5

Не выгорайте

Эндгейм — марафон, а не спринт. Дозируйте вашу еженедельную рутину — 150-200 часов это много контента.

6

Проверяйте роадмап

Игра только что выпущена. Новый контент, герои и функции появятся. Регулярно проверяйте роадмап.
