Бой

Гайд по боссам

У боссов тяжёлая силовая броня, которую обычные атаки не пробивают. Заполните шкалу недуга, чтобы ошеломить их, затем запустите Сигнальные навыки в узком окне. Сначала сломайте броню, затем взрывайте. Уклон всегда лучше, чем завершение комбо.

📖 Время чтения: ~6 мин 👹 Сюжетные + Мировые боссы 🛡️ Система силовой брони
⚡ Быстрый ответ

У большинства боссов есть силовая броня или щиты — сначала сломайте их, прежде чем наносить реальный урон по HP. Заполните шкалу недуга для ошеломления, затем переключайте героев в узком окне для взрывов Сигнальных навыков. Лучшая универсальная команда против боссов: Theresia + Castella + Lute. Против боссов с высокой бронёй используйте Ornette/Alex + Castella. Против боссов с высоким HP используйте Theresia + Roxy для Кровотечения. Всегда уклоняйтесь вместо завершения комбо.

🛡️ Основные механики боссов

  • У элит и боссов есть тяжёлая силовая броня, которую обычные атаки не пробивают
  • Атаки заполняют шкалу недуга — при заполнении враг входит в состояние недуга (ошеломление)
  • Состояния недуга открывают возможности для Сигнальных навыков для массивного урона
  • Вы должны переключать персонажей в узком окне, пока недуг активен
  • Щиты восстанавливаются через короткое время — поддерживайте непрерывное давление

📖 Учебный босс: Орк-воин (Ур.3)

Первый босс в игре

  • Местоположение: За гигантскими воротами в пещере
  • Особенности: Гигантский орк, призывающий гоблинов во время боя
  • Союзник: Johnny помогает вам в этом бою

Механика двойной полосы (HP + Щит)

  • Нужно непрерывно атаковать, чтобы сломать щит прежде чем эффективно damage HP
  • После слома щита защита падает, и вы можете эффективно победить
  • Щит перезаряжается через короткое время — не ослабляйте давление

Боевые советы

  1. Нажмите Shift для переката уклонения от атак босса
  2. Двигайтесь вперёд и атакуйте после уклонения
  3. Атаки Johnny могут подбрасывать (запускать) босса
  4. Прыгайте, чтобы атаковать Орк-воина в воздухе
  5. Используйте атаки Tag Combo для более быстрого завершения

🎯 Универсальная стратегия против боссов

1. Сначала сломайте броню

  • У большинства боссов есть щиты или силовая броня
  • Сломайте щит прежде чем наносить эффективный урон
  • Щиты восстанавливаются — поддерживайте непрерывное давление
  • Герои, ломающие броню: Alex, Ornette, Lute

2. Цепные комбо недугов

  • Используйте Активные навыки для наложения статусных недугов
  • Дождитесь, пока портреты товарищей по команде зажгутся
  • Переключайтесь в узком окне для запуска Сигнальных навыков
  • Повторяйте цикл вместо того, чтобы застревать на одном герое

3. Уклонение > Комбо

  • Никогда не получайте урон только ради завершения комбо
  • Атаки боссов имеют чёткие анимации замаха — уклоняйтесь вовремя
  • Реорганизуйте атаку после уклонения

4. Используйте Воздух / Сбитие

  • Враги в воздухе не могут контратаковать
  • Поверженные враги получают больше урона
  • Примечание: Суперброня предотвращает эти состояния — берите варианты для слома

📋 Известные категории боссов

📖

Сюжетные боссы

Орк-воин (обучение), Дракон (ролик пролога) и другие, встречающиеся во время прохождения основного квеста.

🌍

Мировые боссы

Разбросаны по областям открытого мира. Ежедневное возрождение. Дают материалы для улучшения и карты Кармы. Проверяйте интерактивную карту для местоположений.

🗿

Боссы статуй

Запускаются во время восстановления Статуи Органы: Разрушенный храм (Ур60), Бесплодная торговая стоянка (Тролль Ур60), Деревня чаек (Зверь Ур25), Каньон эха.

🏰

Рейдовые боссы

Мультиплеерные рейдовые боссы. Дропают руны и материалы высокого тира. Требуют скоординированной командной игры.

🍳 Перед боем: Подготовка

  • Съешьте Баффовое рагу Варки (баффы ATK/Крит на 15 мин) перед вызовом боссов
  • Возьмите с собой как минимум один Чай воскрешения на случай падения товарища
  • Экипируйте 3-ч Разрушитель руин на вашего основного DPS для Игнорирования DEF
  • Восстановите ближайшую Статую Органы для nearby якоря лечения
  • Подберите команду под тип босса (броня против HP против обычного)
