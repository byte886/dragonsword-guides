레이나 — 왕국을 지키는 바람

게임 내 주요 공중 런처이자 최강의 저글링 캐릭터 중 한 명. 적을 공중에서 무력하게 유지하여 반격 기회를 제한합니다. 스프린트 + 별도 회피로 높은 기동성을 자랑합니다.

게일 소드
게일 특성
공중 / 출혈
제8기사단장
⚡ 빠른 답변

레이나는 최고의 공중 런처이자 모든 저글링 팀의 핵심입니다. 라이징 커터나 윈드 슬레이어로 적을 띄우고, 윈드 그랩으로 연장한 후, 카스텔라의 지상 내리찍기로 마무리하세요. 최고 팀: 레이나 + 카스텔라 + 루트. 빌드는 루인스브레이커 3세트 + 애저 게일 2세트. 공중은 띄워진 적이 반격할 수 없기 때문에 최강 메커닉 중 하나입니다.

⚔️ 모든 스킬 설명

스킬 유형 효과 활용 사례
라이징 커터 (Rising Cutter) 액티브 1 공중 적용 근거리 런처. 주요 콤보 오프너.
윈드 슬레이어 (Wind Slayer) 액티브 2 공중 적용 더 넓은 범위일 가능성. 군상용 대체 런처.
템페스트 (Tempest) 시그널 A 기절한 적에게 발동. 출혈 적용. 아군이 기절 적용 후 교체 진입. 추가 피해 + 출혈 세팅.
윈드 그랩 (Wind Grab) 시그널 B 공중인 적에게 발동. 공중 연장/증가. 핵심 저글링 연장기. 적을 더 오래 공중에 머무르게 함.

🔗 스킬 시너지 체인

🪽

공중 체인

라이징 커터 / 윈드 슬레이어 → 적 공중 → 윈드 그랩 (시그널 B) → 공중 지속 시간 연장 → 반복 또는 아군으로 마무리

🩸

기절 → 출혈 체인

아군 기절 적용 → 레이나로 교체 → 템페스트 (시그널 A) → 출혈 적용 → 출혈 피해로 콤보 지속

이 빌드를 선택하는 이유

  • 루인스브레이커 3세트 — 보스 방어 관통용 방어 무시
  • 애저 게일 2세트 — 게일/공중 피해 +15%. 레이나의 모든 키트를 직접 증폭합니다.
  • 상태 이상 효율 — 더 빠른 공중 스택 = 더 많은 저글링 시간

👥 최고 팀 구성

팀 최적 상황 핵심 루프
레이나 + 카스텔라 + 루트 최고 공중 팀 레이나 띄우기 → 템페스트 → 루트 연장 → 카스텔라 지상 내리찍기 폭딜
레이나 + 테레지아 + 카스텔라 종합 콘텐츠 최고 범용 현재 종합 콘텐츠 벤치마크. 거의 모든 활동에 통합니다.
레이나 + 아일린 + 아리아 균형 잡힌 공중 아일린과 아리아가 공중과 원거리 딜 지원
레이나 + 아일린 + 칼시온 화염 공중 칼시온의 화상이 레이나의 띄우기와 원소 시너지
레이나 + 아일린 + 세레세 빙결 공중 세레세의 빙결이 레이나의 띄우기와 빙결-저글링 시너지
레이나 + 샬롯 액션 중심 종합 콘텐츠 샬롯이 압박 주도, 레이나가 공중과 간격 지원
레이나 + 테레지아 + 록시 공중 + 출혈 레이나가 띄우고, 테레지아/록시가 공중 창 동안 딜

🪽 공중 콤보 시퀀스

레이나 + 카스텔라 + 루트 — 풀 저글링 루프

  1. 레이나로 시작 — 라이징 커터 또는 윈드 슬레이어로 대상을 띄웁니다
  2. 즉시 템페스트 — 적이 떠오르는 동안 레이나의 템페스트 시그널 스킬을 발동합니다
  3. 루트로 교체 — 루트의 시그널 스킬을 발동하여 공중 지속 시간을 연장합니다
  4. 카스텔라로 전환 — 대상을 땅에 내리찍어 막대한 피해를 줍니다
  5. 반복 — 루프하여 공중 창 제어를 유지합니다
💡 공중이 사기인 이유

공중은 게임 내 최강 메커닉 중 하나입니다. 공중에 매달린 적은 반격 기회가 제한적이기 때문입니다. 방어도 못 하고, 슈퍼 아머도 발동 못 하고, 특수 공격도 사용 못 합니다. 잘 실행된 저글링 = 공짜 피해 창입니다.

💨 기동성: "모바일 브릿지"

레이나는 어떤 팀의 "브릿지"가 되게 하는 독특한 기동성 옵션을 가지고 있습니다:

  • 스프린트 스타일 이동 — 간격을 회복하는 긴 대시
  • 별도 회피 — 커밋된 공격용 짧은 회피
  • 두 가지 재배치 옵션 — 긴 스프린트로 간격을 회복하고, 짧은 회피는 다음 커밋 공격을 위해 아껴두세요

✅ 장점

🪽

S티어 공중 코어

주요 공중 런처. 모든 저글링 팀 구성에 필수적입니다.

⚡

이중 런처

라이징 커터와 윈드 슬레이어 모두 공중 적용. 어떤 상황이든 유연한 콤보 오프너.

🔄

이중 시그널 스킬

템페스트(기절 발동)와 윈드 그랩(공중 발동). 두 가지 다른 상태 이상에 반응합니다.

💨

높은 기동성

스프린트 + 별도 회피 = 두 가지 재배치 옵션. 게임 내 최고 기동성 키트.

🎪

최고 저글러

적을 공중에 유지하여 반격을 제한. 어려운 전투에서 더 긴 공격 체인을 만듭니다.

🔧

범용 적합

3번 멤버로 많은 팀에 들어갈 수 있습니다. 화염, 빙결, 출혈, 중독 아키타입과 모두 호흡합니다.

❌ 단점

  • 공중 의존 — 슈퍼 아머 적 상대에서는 공중이 실패하고 레이나의 가치가 크게 떨어집니다
  • 아군 필요 — 최고 성능을 내려면 공중 창을 활용할 카스텔라 같은 마무리러가 필요합니다
  • 근거리 리스크 — 높은 기동성에도 여전히 근거리라 처벌받을 수 있습니다
  • 출혈은 부가적 — 템페스트의 출혈은 보너스 효과일 뿐 주요 피해원이 아닙니다
  • 실행 필요 — 저글링 지속 시간을 최대화하려면 정확한 공중 타이밍과 교체 리듬이 필요합니다

🎮 전투 팁

  1. 런처로 시작 — 항상 라이징 커터나 윈드 슬레이어로 시작하여 적을 공중으로 띄우세요
  2. 기절에 템페스트 — 아군이 기절 적용하면 레이나로 교체하여 템페스트로 출혈을 거세요
  3. 윈드 그랩으로 연장 — 띄운 직후 윈드 그랩을 사용하여 적을 더 오래 공중에 머무르게 하세요
  4. 두 회피 모두 사용 — 긴 스프린트는 간격 회복, 짧은 회피는 공격 간격. 둘 다 낭비하지 마세요
  5. 카스텔라와 페어 — 공중 창이 끝나기 전에 카스텔라로 교체하여 지상 내리찍기 마무리를 하세요
  6. 루트가 체인 연장 — 공중 팀에서 루트가 공중 지속 시간을 더 연장할 수 있습니다
  7. 공중 유지 — 공중 상태의 적은 반격이 제한적입니다. 저글링 = 안전입니다.

⚠️ 흔한 실수

❌

슈퍼 아머에 공중 강요

슈퍼 아머 적 상대에서는 공중이 효과가 없습니다. 다른 전략으로 바꾸거나 갑옷 파괴자를 데려오세요.

❌

띄운 후 교체 안 함

띄우고 레이나에 머무르는 것은 공중 피해 창을 낭비하는 것입니다. 즉시 마무리러로 교체하세요.

❌

템페스트 출혈 무시

템페스트의 출혈은 공짜 추가 피해원입니다. 기절이 적용되면 항상 사용하세요.

❌

이중 회피 낭비

레이나의 기동성이 가장 큰 장점입니다. 두 회피 옵션을 전략적으로 사용하세요.

❌

원거리처럼 플레이

레이나는 근거리 공중 캐릭터입니다. 원거리를 원한다면 세레세나 오델로를 선택하세요.

❌

애저 게일 세트 없음

애저 게일 2세트는 공중 피해에 핵심적입니다. 건너뛰지 마세요.
