영웅 빌드

완전 빌드 가이드

모든 영웅별 최고 장비 세트, 카르마 무기, 주요 스탯, 룬. 빌드 가정: 완전 각성한 영웅, 최고 레벨 카르마나 완벽한 부 스탯은 아님.

📖 읽는 시간: 약 10분 ⚔️ 16명 영웅 빌드 🔄 2026년 8월 업데이트
⚡ 빠른 빌드 공식
  1. 먼저 영웅을 완전 각성하세요 (패시브와 강화된 세트 효과 잠금 해제)
  2. 핵심으로 3피스 루인스브레이커를 사용하세요 (거의 모두에게 방어 무시)
  3. 약 80% 치명타 확률과 약 150% 치명타 피해를 목표로 하세요
  4. 영웅의 상태 이상에 맞는 2피스 원소 세트를 추가하세요
  5. 팀: 한 영웅이 상태 이상을 적용하면 다음이 폭발시킵니다

📊 범용 스탯 우선순위

🎯

치명타 확률 ~80%

첫 번째 목표. 80% 미만이면 피해 일관성이 너무 많이 손실됩니다. 가슴과 다리에 우선순위를 두세요.

💥

치명타 피해 ~150%

치명타 확률이 캡되면 치명타 피해를 스택하세요. 모든 빌드의 주요 피해 배율.

⚡

부 스탯 우선순위

추가 위력 > 공격력 증가 > 방어 무시. 장비를 재단련하여 이 순서로 굴리세요.

* 알렉스, 시온, 타르트 빌드는 아직 테스트 중입니다. 커뮤니티 테스트가 진행됨에 따라 데이터가 업데이트됩니다.

🔥 원소별 빌드 로직

베놈 / 중독 (조니 + 샬롯)

  • 조니 — 주요 베놈 DPS, 필드에 중독 유지. 2피스 베놈포그 셰이드가 중독 피해를 증폭합니다.
  • 샬롯 — 폭발 천장에 도달하려면 조니가 중독을 유지해줘야 합니다. 둘은 서로를 위해 설계되었습니다.

블레이즈 / 화상 (아리아 + 칼리엔 + 칼시온)

  • 아리아 — 인에이블러. 화상과 공중을 동시에 적용. 레이나와 칼시온을 위한 최고 세팅 영웅. 3피스 블레이징 플레임 사용.
  • 칼리엔 — 여우 분신으로 화상을 빠르게 스택. 폭스 그랩과 피날레가 폭발 + 기절을 전달.
  • 칼시온 — 강력한 타격자. 웨폰 블레이즈가 피해를 강화하지만, 최고조에 달하려면 공중과 화상 인에이블러가 필요합니다.

프로스트 / 빙결 (오델로 + 세레세 + 다나)

  • 세레세 — 최고의 빙결 적용자. 다중 히트 피해 + 강력한 제어 군집. 약점: 대형 보스 (긴 애니메이션, 아이스 스톰 불리).
  • 오델로 — 프로스트바이트 DPS. 최대 피해 창을 발동하려면 빠른 빙결 스택이 필요. 전용 카르마가 낮은 기본 치명타 패시브를 보상합니다.
  • 다나 — 유연함. 오프필드에서 빙결 딜, 패밀리어로 적을 견제, 퍼펙트 패리 후 팀 실드 제공.

출혈 / 기절 (록시 + 테레지아 + 아스트리아)

  • 록시 — 모든 거리에서 빠른 출혈 스택이지만, 피해를 최대화하려면 기절이 필요. 테레지아와 아스트리아가 자연스러운 파트너.
  • 테레지아 — 온필드 DPS. 출혈과 강한 기절을 동시에 적용.
  • 아스트리아 — 기동성을 피해로 맞바꿈. 비 같은 화살이 기절과 브레이크를 스택. 아군이 적을 제어하는 동안 딜. 치명타 확률이 최우선.

게일 / 공중 (레이나 + 아일린)

  • 레이나 — 단일 대상 전문가. 공중인 적에 긴 스킬 콤보 체인. 2피스 애저 게일이 게일 피해를 직접 증폭. 아리아가 최고 인에이블러.
  • 아일린 — 공격적 각도에서 공중 지원. 팀 이동 속도와 공격력 부스트. 견고한 치명타를 가진 빠른 교체 캐릭터로 잘 어울림. 가장 유연한 장비 (발라드 오브 라이프 또는 루인스브레이커).

썬더 / 감전 (오르네트)

  • 오르네트 — 대부분의 팀을 이끌 수 있는 강력한 썬더볼트 영웅. 감전 팀에서 최고조. 2피스 썬더러시는 필수.
  • 시온과 타르트를 사용할 수 없을 때, 루트가 대체 파트너로 작동합니다 (힐링과 공격력 버프가 오르네트의 딜을 지속).

🌟 특수 영웅

⚔️

루트

게임 내 단 둘뿐인 힐러 중 하나 (다른 하나는 타르트). 거의 모든 팀에 범용 선택. 첫 각성 노드가 팀 공격력을 부스트. 넉아웃과 기절 팀에 적합. 2피스 홀리 아비터가 힐링 출력을 제공하고, 루인스브레이커가 개인 딜을 유지합니다.

✨

타르트

다른 힐러. 빌드는 아직 최종 테스트 중. 생존이 병목이 되는 고난이도 콘텐츠에서 가치가 크게 상승합니다.

🗡️ 전용 카르마 획득

전용 카르마 무기(조니의 방랑하는 검이나 세레세의 영원한 눈보라 같은)는 획득하려면 잔영의 파편과 기억이 필요합니다.

  • 이 재료를 파밍하는 것이 기능적 빌드와 완전히 최적화된 빌드 사이의 주요 성장 관문입니다
  • 완벽한 룬 부 스탯을 쫓기 전에 메인으로 플레이할 영웅의 파편 파밍을 우선하세요
  • 기본 카르마는 교환 상점에서 구매할 수 있으며 영웅 특정이 아닙니다
  • 동일한 기본 카르마 7개를 사용하여 최고 레벨로 승급합니다 (1개 기본 + 6개 복제)
  • 월드 보스가 기본 카르마를 드롭할 수 있습니다 (RNG), 매일 파밍 가능

🤝 팀 빌딩 원칙

💡 핵심 인사이트

대부분의 DPS 영웅은 피해 천장에 도달하려면 최소 하나의 특정 조건이 필요합니다:

  • 레이나와 칼시온은 공중이 필요합니다
  • 오델로는 빙결 스택이 필요합니다
  • 샬롯은 필드에 중독이 필요합니다
  • 록시는 기절이 필요합니다

팀을 최종 확정하기 전에, 메인 DPS에게 무엇이 필요한지 파악하고 최소 한 명의 팀메이트가 안정적으로 적용할 수 있는지 확인하세요.
