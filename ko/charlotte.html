샬롯 — 정보원

고위험 고수익 근거리 암살자 DPS. 중독을 적용한 후 공중으로 전환하여 콤보 체인을 엽니다. 스텔스 분신이 추가 압박을 더합니다. 숙련된 플레이에 강하지만 실수는 크게 처벌됩니다.

쌍둥이 단검
베놈 특성
중독 / 공중 / 넉다운
교환 상점
⚡ 빠른 답변

샬롯은 가장 다재다능한 S티어 영웅 중 한 명입니다. 중독을 적용한 후 공중으로 전환하여 지속적인 시그널 스킬과 태그 콤보 체인을 가능하게 합니다. 최고 팀: 샬롯 + 조니 + 레이나. 빌드는 루인스브레이커 3세트 + 베놈포그 셰이드 2세트. 높은 스킬 천장 — 안전한 원거리 플레이를 원하는 분에게는 맞지 않습니다.

스탯 우선순위

  1. 공격력 — 샬롯의 역할은 모든 기회에 피해를 입히는 것입니다
  2. 상태 이상 효율 — 중독, 넉다운, 공중 압박이 단독 압박을 시그널 스킬 시퀀스로 전환합니다
  3. 치명타 확률 & 치명타 피해 — 암살 창의 스케일을 적절하게 만듭니다
  4. 생존 — 죽음이 실제로 클리어를 막을 때만 추가하세요. 너무 방어적이면 샬롯의 가치가 줄어듭니다

👥 최고 팀 구성

팀 최적 상황 핵심 루프
샬롯 + 조니 + 레이나 최고 딜 팀 샬롯 메인 DPS, 조니 보조 DPS, 레이나 콤보 서포트. 게임 내 최고 구성 중 하나.
샬롯 + 레이나 액션 중심 종합 콘텐츠 샬롯이 압박을 주도, 레이나가 공중과 간격을 지원. 샬롯이 드라이버, 레이나가 팀이 공중으로 뜨거나 재배치하도록 돕습니다.
샬롯 + 조니 + 아일린 중독-공중 팀 아일린이 버퍼와 공중 적용자, 샬롯이 딜. 안정적인 중독 DoT + 공중 폭딜.
샬롯 + 아일린 + 다나 "고통 열차" 아일린이 버프, 샬롯이 적을 끌어당겨 내리찍기, 다나가 중독 단독 스택.
샬롯 + 루트/레이나 범용 3번 슬롯은 필요에 따라: 힐링은 루트, 콤보 연장은 레이나.

🔄 전투 흐름 (6단계)

  1. 공중 반응 테스트 — 전투 시작 시 적이 공중에 어떻게 반응하는지 테스트하세요
  2. 카메라 가독성 유지 — 근거리 캐릭터는 나쁜 카메라 앵글로 고통받습니다. 신중하게 포지셔닝하세요
  3. 점등된 아군 입력 사용 — 시그널 스킬 창이 나타나면 즉시 교체하세요
  4. 간격 조절에 레이나 사용 — 이탈이 필요할 때 레이나로 교체하여 안전하게 재배치하세요
  5. 샬롯으로 복귀 — 아군 교체를 통해 전투 리듬을 리셋하세요
  6. 중독 먼저, 그다음 공중 — 중독을 먼저 스택한 후 공중으로 전환하여 콤보를 여세요

✅ 장점

🏆

S티어 다재다능

가장 팀을 꾸리기 쉬운 영웅 중 한 명. 거의 모든 영웅보다 더 많은 팀 구성에 들어갑니다.

☠️

이중 상태 이상 파워

중독과 공중을 모두 적용. 중독 압박을 공중 콤보 기회로 전환합니다.

👤

스텔스 분신

투명 스킬이 분신을 생성. 전용 카르마로 분신이 도약 폭발하여 추가 피해를 줍니다.

💨

높은 기동성

빠른 접근과 이탈을 가진 암살자 포지션. 지상과 공중 콤보를 빠르게 전환합니다.

🔗

콤보 드라이버

팀 시그널 스킬과 태그 콤보 시퀀스를 엽니다. 공격형 팀을 작동시키는 엔진입니다.

📈

초반 강함

중독은 초반(레벨 50 이전)에 매우 잘 통합니다. 성장에 탁월합니다.

❌ 단점

  • 높은 스킬 요구 — 높은 투자, 높은 수익. 정확한 회피와 타이밍이 필요합니다
  • 근거리 처벌 — 원거리 구성보다 관대하지 않습니다. 실수가 크게 처벌됩니다
  • 카메라 이슈 — 근거리 전투는 가독성 없는 카메라 앵글로 이어질 수 있습니다
  • 중독 후반 약세 — 레벨 50 이후 보스는 중독 저항이 높아질 수 있습니다
  • 아군 필요 — 최고 성능을 내려면 레이나나 유사 서포트가 필요합니다

🎮 전투 팁

  1. 공중 먼저 테스트 — 항상 전투 시작 시 적의 공중 반응을 테스트하세요
  2. 카메라 가독성 유지 — 근거리에서 포지셔닝을 주시하여 카메라 가림을 피하세요
  3. 점등된 아군 입력 사용 — 시그널 스킬 창이 나타나면 즉시 교체하세요
  4. 간격 조절에 레이나 — 간격을 만들거나 재배치가 필요할 때 레이나로 교체하세요
  5. 중독 오프너 — 중독을 먼저 스택한 후 공중으로 전환하여 콤보를 여세요
  6. 분신 폭발 — 전용 카르마 효과를 사용하여 분신이 도약 폭발하도록 하여 추가 피해를 얻으세요
  7. 빠른 리셋 — 압박이 떨어질 때 아군 교체로 전투 리듬을 리셋하세요

⚠️ 흔한 실수

❌

너무 방어적

생존 스탯에 과도하게 투자하면 샬롯의 딜 가치가 줄어듭니다. 죽음이 실제 문제일 때만 방어를 추가하세요.

❌

상태 효율 무시

상태 이상 효율이 없으면 중독 스택이 너무 느립니다. 이 스탯이 그녀 로테이션의 핵심입니다.

❌

분신 낭비

스텔스 분신과 전용 카르마 폭발을 활용하지 않는 것은 그녀 피해의 상당 부분을 낭비하는 것입니다.

❌

나쁜 카메라 추격

카메라가 가독성 없을 때 압박을 추구하면 처벌받습니다. 이탈하고 재배치하세요.

❌

레이너 서포트 없음

샬롯의 최고 성능에는 레이나 같은 아군이 필요합니다. 솔로 캐리로 쓰면 천장이 제한됩니다.

❌

원거리처럼 플레이

샬롯은 근거리 암살자입니다. 안전한 원거리 플레이를 원한다면 세레세나 오델로를 선택하세요.
