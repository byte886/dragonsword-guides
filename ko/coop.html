협동 가이드

드래곤소드: 어웨이크닝은 사냥(2인)과 레이드(3인)를 통해 제한된 협동을 지원합니다. 오픈월드나 스토리 협동은 없습니다. 초대 코드로 참여하세요 — 매치메이킹 없고, 친구 목록도 필요 없습니다. 각 플레이어는 자신의 완전한 3영웅 파티를 가져옵니다.

📖 읽는 시간: 약 5분 👥 사냥 2P / 레이드 3P 🔗 초대 코드만
⚡ 빠른 답변

사냥(2P)과 레이드(3P)만 협동을 지원합니다. 오픈월드, 스토리, 시련의 탑 멀티플레이어는 없습니다. 모든 세션은 로비 생성과 초대 코드 공유가 필요합니다. 매치메이킹 없음 — 코드로 친구만 가능합니다. 각 플레이어는 자신의 3영웅 파티를 사용합니다. 빠른 재시도 없음 — 매번 돌 때마다 로비를 다시 만들어야 합니다. 게임은 기본적으로 싱글플레이어 경험입니다.

✅ 협동 지원 콘텐츠

모드 최대 플레이어 설명
사냥 (토벌) 2인 폐쇄형 아레나 보스 전투. 각 플레이어는 자신의 3영웅 파티를 가져옵니다.
레이드 3인 고난이도 인스턴스 콘텐츠. 솔로나 최대 2명의 친구와 플레이할 수 있습니다.

❌ 협동 불가 콘텐츠

  • 메인 스토리 — 캠페인은 싱글플레이어 전용입니다
  • 오픈월드 탐험 — 지도를 함께 탐험할 수 없습니다
  • 시련의 탑 — 종합 도전 과제는 솔로 전용입니다
  • 일반 필드 탐험 — 오버월드 협동이 없습니다
  • 사이드 퀘스트 — 모든 퀘스트는 싱글플레이어입니다
  • PvP — 플레이어 대 플레이어 모드가 존재하지 않습니다

🎮 협동 플레이 방법

  1. 호스트가 로비 생성 — 멀티플레이어 메뉴를 열고 새 세션을 만듭니다
  2. 콘텐츠 & 난이도 선택 — 호스트만 사냥/레이드와 난이도를 선택할 수 있습니다
  3. 초대 코드 생성 — 로비가 고유 초대 코드를 생성합니다
  4. 코드 공유 — 초대 코드를 친구에게 보냅니다
  5. 친구가 코드 입력 — 친구가 초대 코드를 입력하여 로비에 참여합니다
  6. 전투 시작 — 모두 준비되면 전투를 시작합니다
  7. 이후 로비 해산 — 다음 돌을 위해 로비 전체를 다시 만들어야 합니다

⚙️ 협동 메커니즘

🔗

초대 코드 시스템

고유 초대 코드로 참여합니다. 스팀 친구 목록이 필요 없습니다. 매치메이킹 없음 — 코드를 가진 사람과만 플레이할 수 있습니다.

👥

각 플레이어 = 완전 파티

모든 플레이어는 자신의 완전한 3영웅 파티를 가져옵니다. 3인 레이드에서는 동시에 9명의 영웅이 필드에 나옵니다.

🏠

호스트가 모든 것을 제어

로비 호스트만 콘텐츠와 난이도를 선택합니다. 설정이 틀리면 로비 전체를 해산하고 다시 만들어야 합니다.

🔄

빠른 재시도 없음

사냥이나 레이드 완료 후 로비가 자동으로 해산됩니다. 다음 돌을 위해 전체 로비 생성 과정을 다시 거쳐야 합니다.

👍 협동의 장점

  • 더 쉬운 고난이도 콘텐츠 — 레이드와 고티어 사냥은 친구와 함께하면 훨씬 수월합니다
  • 사회적 경험 — 함께 보스를 공략하고 도전을 공유합니다
  • 플레이어당 완전 파티 — 각 플레이어가 3명의 영웅을 가지고 있어 풍부한 전술 조합을 만듭니다
  • 간단한 초대 시스템 — 친구 목록 필요 없이 코드만 공유하면 됩니다
  • 레이드는 솔로 또는 협동 가능 — 선호도와 파티 위력에 따라 선택하세요

👎 제한 & 문제점

  • 매우 제한된 콘텐츠 — 사냥과 레이드만. 오픈월드 협동은 전혀 없습니다
  • 번거로운 워크플로우 — 매번 돌 때마다 로비를 다시 만들어야 하고 빠른 재시도가 없습니다
  • 호스트 전용 설정 — 호스트만 콘텐츠/난이도를 고릅니다. 설정이 틀리면 전체 재시작입니다
  • 매치메이킹 없음 — 랜덤 플레이어와 플레이할 수 없고 친구만 가능합니다
  • 게스트 진행 불명확 — 게스트 진행이 저장되는지 완전히 문서화되지 않았습니다
  • 잠금 해제 조건 불명확 — 멀티플레이어가 정확히 언제 잠금 해제되는지 잘 문서화되지 않았습니다
  • 모드 충돌 — 모드가 온라인 플레이를 막을 수 있습니다 (양쪽 플레이어가 동일한 모드나 우회 패치가 필요)

💡 협동 팁

1

파티 조율

미리 친구와 팀 구성에 대해 이야기하세요. 최대 효율을 위해 다른 속성과 역할(DPS, 서포터, 파괴자)을 커버하세요.

2

호스트는 미리 계획

호스트로서 로비를 만들기 전에 어떤 사냥/레이드와 난이도를 원하는지 정확히 알고 가세요. 설정이 틀리면 전체 재시작입니다.

3

버프 음식 가지고 가기

각 플레이어는 참여 전에 자신의 삶기 버프 스튜를 먹어야 합니다. 15분 공격력/치명타 버프가 파티 전체에 중첩됩니다.

4

종합 콘텐츠에만 사용

협동은 정말 고난이도 레이드와 사냥에만 유용합니다. 스토리와 오픈월드는 솔로 플레이용으로 설계되었습니다.

🔮 향후 협동 업데이트

개발자 로드맵에 따르면 향후 업데이트에서 다음이 추가될 수 있습니다:

  • 더 많은 협동 지원 활동
  • 차원 균열 시스템 (차원 균열)
  • 추가 무료 영웅
  • 개인 / 개별 퀘스트

참고: 게임은 2026년 7월 23일 출시되었습니다. 협동 기능은 향후 업데이트로 확장될 가능성이 높습니다.
