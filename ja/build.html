ヒーロービルド

完全なビルドガイド

全ヒーローの最強装備セット、カルマ武器、メインステータス、ルーン。ビルド前提: 完全覚醒したヒーロー、カルマは最大レベルでも完璧なサブステータスでもない。

📖 読了時間: 約10分 ⚔️ 16ヒーローのビルド 🔄 2026年8月更新
⚡ クイックビルドフォーミュラ
  1. まずヒーローを完全覚醒 (パッシブと強化されたセット効果をアンロック)
  2. コアとして3-piece ルインズブレイカーを使用 (ほぼ全員にDEF無視)
  3. クリティカル率約80%とクリティカルダメージ約150%を目標
  4. ヒーローの状態異常に合わせた2-piece元素セットを追加
  5. チーム: 1人が状態異常を付与し、次がそれをデトネート

📊 全ヒーロー共通ステータス優先順位

🎯

クリティカル率 ~80%

最初の目標。80%を下回るとダメージの安定性が大きく損なわれる。胸と脚で優先。

💥

クリティカルダメージ ~150%

クリティカル率がキャップしたら、クリティカルダメージをスタック。全ビルドのプライマリダメージ乗数。

⚡

サブステータス優先順位

追加パワー > ATKパワーアップ > DEF無視。装備をリフォージしてこの順番でロール。

🔥 元素別ビルドロジック

毒 / ポイズン (Johnny + Charlotte)

  • Johnny — メイン毒DPS、フィールド上で毒を維持。2-piece ベノムフォグシェイドが毒ダメージを増幅。
  • Charlotte — バースト上限に到達するにはJohnnyが毒を維持する必要がある。2人は互いのために設計されている。

火 / バーン (Aria + Kalien + Kalsion)

  • Aria — エネイブラー。火傷と浮遊の両方を同時に付与。ReinaとKalsionの最高のセットアップヒーロー。3-piece ブレイジングフレイムを使用。
  • Kalien — キツネクローンを通じて火傷を急速にスタック。キツネグラブとフィナーレがバースト + スタンを提供。
  • Kalsion — 重撃手。ウェポンブレイズがダメージを強化するが、ピークには浮遊と火傷のエネイブラーが必要。

氷 / フリーズ (Othello + Cerese + Dana)

  • Cerese — 最高の氷結付与者。多段ヒットダメージ + 強力な制御グルーピング。弱点: 大型ボス (長いアニメーション、アイスストームのデメリット)。
  • Othello — フロストバイトDPS。最大ダメージウィンドウを発動するには速い氷結スタックが必要。専用カルマが低いベースクリティカルパッシブを補う。
  • Dana — 柔軟。オフフィールドで氷結ダメージを与え、使い魔で敵を牽制、パーフェクトパリィ後にチームシールドを提供。

出血 / スタン (Roxy + Theresia + Astria)

  • Roxy — あらゆる距離で速い出血スタックだが、ダメージを最大化するにはスタンが必要。TheresiaとAstriaが自然なパートナー。
  • Theresia — オンフィールドDPS。出血と重いスタンの両方を同時に付与。
  • Astria — 機動力をダメージと交換。雨のような矢がスタンとブレイクをスタック。味方が敵を制御している間に出力。クリティカル率が最優先。

疾風 / 浮遊 (Reina + Eileen)

  • Reina — 単体スペシャリスト。浮遊中の敵に長いスキルコンボチェーン。2-piece アズールゲイルが疾風ダメージを直接増幅。Ariaが最高のエネイブラー。
  • Eileen — 攻撃的な角度から浮遊をサポート。チームの移動速度とATKをブースト。堅実なクリティカルを持つ速い切り替えキャラクターとして優秀。最も柔軟な装備 (生命のバラードまたはルインズブレイカー)。

雷 / 感電 (Ornette)

  • Ornette — ほとんどのチームを率いられる強力なサンダーボルトヒーロー。感電チームでピーク。2-piece サンダーラッシュが必須。
  • SionとTarteが利用できない場合、Luteが代替パートナーとして機能 (回復とATKバフがOrnetteの出力を維持)。

🌟 特殊ヒーロー

⚔️

Lute

ゲーム内で唯一の2人のヒーラーの1人 (もう1人はTarte)。ほぼすべてのチームの万能選択。最初の覚醒ノードがチームATKをブースト。ノックアウトとスタンチームにフィット。2-piece ホーリーアービターが回復出力を提供し、ルインズブレイカーが個人ダメージを維持。

✨

Tarte

もう1人のヒーラー。ビルドは現在最終テスト中。生存がボトルネックになる高難易度コンテンツで価値が大幅に上昇。

🗡️ 専用カルマ入手方法

専用カルマ武器 (Johnnyの放浪の剣やCereseの永遠のブリザードなど) は入手に残像の欠片と記憶が必要です。

  • これらの素材をファームすることが、機能するビルドと完全最適化されたビルドの間の主な進行ゲート
  • 完璧なルーンサブステータスを追う前に、メインにする予定のヒーローの欠片ファームを優先
  • 基本カルマは交換ショップで購入可能で、ヒーロー固有ではない
  • 7つの同一の基本カルマを使用して最大レベルに昇華 (1ベース + 6レプリカ)
  • ワールドボスが基本カルマをドロップ可能 (RNG)、デイリーでファーム可能

🤝 チーム編成原則

💡 重要な洞察

ほとんどのDPSヒーローはダメージ上限に到達するために少なくとも1つの特定の条件が必要です：

  • ReinaとKalsionは浮遊が必要
  • Othelloは氷結スタックが必要
  • Charlotteはフィールド上の毒が必要
  • Roxyはスタンが必要

チームを確定する前に、メインDPSが何を必要としているかを特定し、少なくとも1人のチームメイトがそれを確実に付与できることを確認しましょう。
