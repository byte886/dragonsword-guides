Lute — 主人公

主人公であり、ゲーム内でわずか2人しかいないヒーラーの1人。ほぼすべてのチームの3枠目に収まる万能ユーティリティヒーローで、回復、アーマーブレイク、チームバフを提供します。

初期ヒーロー
アンプリチュード特性
スタン / 回復 / ダウン
近接大剣
⚡ クイックアンサー

Luteは最も初心者に優しいヒーローであり、ゲーム内で最も安全な投資です。無料アンロック、パーティを回復、アーマーをブレイク、文字通りどんなチームでも機能します。防御的にビルドし、パーティ回復のために6★まで覚醒させ、戦闘が難しすぎると感じたときはいつでも3枠目として使用しましょう。

防御 / サポートビルド (推奨)

装備セット

2 ホーリーアービター + 3 ルインズブレイカー

ホーリーアービターは回復量をブーストし、ルインズブレイカーはDEF無視を提供して個人のダメージ貢献を維持します。

メインステータス

ATKパワーアップ → クリティカルダメージ → クリティカルヒット確率

純粋なサポートビルドの場合: DEF、HP、回復効果

専用カルマ

🪽 浮遊コンボループ

Reina + Castella + Lute

  1. Reinaがライジングカッターまたはウィンドスレイヤーでターゲットを打ち上げ
  2. ターゲットが上昇する際、Reinaのテンペストシグナルスキルを発動
  3. Luteに切り替え — シグナルスキルで浮遊時間を延長
  4. Castellaに切り替え — ターゲットを地面に叩きつけて大ダメージ
  5. ループを繰り返して浮遊ウィンドウの制御を維持

✅ 強み

🎁

無料の初期ヒーロー

最初から使用可能。チケットもアンロックの苦労も不要 — ただプレイして投資するだけ。

💚

2人いるヒーラーの1人

LuteとTarteだけが回復可能。6★覚醒でLuteはパーティ全体回復を提供。

🔄

万能フレックス枠

3枠目として事実上どんなチームにも収まる。ユーティリティピックの定義。

🛡️

デュアル状態サポート

スタンとダウンの両方のチーム原型をサポート。ボスアーマーもブレイク。

📈

チームバフ

覚醒ノードがチームATKブーストとパーティ回復を提供。全員を強化。

🏆

生存保険

長いボス戦で、純ダメージチームが全滅するときにLuteがパーティを生かし続ける。

❌ 弱み

  • 個人ダメージが低い — サポートとして、DPSは純ダメージディーラーに匹敵しない
  • 絶対的な最強エンドゲームチームには入らない — トップエンドチーム (Theresia + Reina + Castella) はLuteを起用しない
  • 覚醒が必要 — パーティ回復は6★でのみアンロック; 序盤の回復は限定的
  • 防御的なプレイスタイル — 生存のために設計され、ダメージを担うためではない。メインDPSではない。

🎮 戦闘のコツ

  1. 緊急切り替え — パーティのHPが低いとき、Luteに切り替えて癒しの輪を発動
  2. アーマーブレイクオープナー — ボス戦をLuteで始めてパワーアーマーをブレイク、その後DPSに切り替え
  3. 浮遊エクステンダー — 浮遊チームでは、Reinaが打ち上げた後にLuteに切り替えてウィンドウを延長
  4. 攻撃をタンク — 緊急時にLute (防御ビルド) に切り替えてダメージを吸収
  5. チームバフの維持 — Luteの覚醒バフをアクティブに保ち、一貫したパーティATKブーストを
  6. フレックス枠の心構え — 戦闘の要求に応じてダメージと生存の間で調整

⚠️ よくある間違い

❌

メインDPSとしてビルド

Luteはサポート。純ダメージに投資すると回復とユーティリティの可能性を無駄にする。

❌

覚醒を無視

6★のパーティ回復が彼の決定的な特徴。覚醒優先度をスキップしないこと。

❌

すべてのチームに起用

純ダメージのエンドゲームチームはLuteを必要としない場合がある。いつ彼を外すかを知ろう。

❌

DEFステータスをスキップ

完全な防御ビルドでLuteは実際に攻撃をタンクできる。ガラスキャノンのLuteは即死する。
