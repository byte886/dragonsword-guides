シオン — オルガナの化身

女神オルガナの化身。シオンは敵を集めて感電を付与し、味方のAoEバーストの機会を作ります。現在Bティアですが、チーム編成の発展により最も上昇する可能性が高い英雄とされています。

Organa Order
Thunderbolt Trait
Shock / Knockdown
Hybrid Support
⚡ Quick Answer

シオンは密集した敵を集めて感電を付与し、味方のAoEバースト機会を作る感電サポートです。聖遺物は配置と回収時の両方でダメージと感電判定が発生します。現在Bティアですが密集グループではそれ以上の性能を発揮し、最も上昇可能性の高い英雄です。オルネット、タルトとの感電チーム、またはリュートとのバランス型が最適。

⚡ Combat Style

シオンのコアメカニクスは聖遺物（ソンムル）で、敵を一箇所に集める展開フィールドです。聖遺物は展開時と回収時の両方でダメージと感電判定を付与 — 適切なタイミングで回収することで1回の使用で2回の感電付与が得られます。

これによりシオンは密集した敵集団に対して非常に優れています：敵を集めて感電を付与し、オルネットのようなAoE特化の味方がバーストダメージを放つ窓を作り出します。彼の価値は状況に大きく依存 — 単体や散らばった敵には集敵ユーティリティが無駄になります。

Gear Sets

サンダーラッシュ3セット + ルインズブレイカー2セット（または感電3+ダウン2）

サンダーラッシュは感電ダメージと状態異常速度を向上。ルインズブレイカーは防御無視を追加。代替：ノックダウン連鎖重視なら感電3+ノックダウン2。

Main Stats

攻撃力 → 会心率 → 会心ダメージ

サポート特化ビルド：攻撃速度、状態異常付与率

スキル優先度

攻撃ブランチのダメージノードとクリティカル関連パッシブを優先。長クールダウンのアクティブよりコアパッシブに集中。

  2. タルテが集団に追加の感電デバフを蓄積
  3. シオンが聖遺物を回収し2回目の感電付与とダメージ
  4. オルネットが集団の感電敵に広範囲鎌AoEで交代出撃
  5. 感電時間中にシグナルスキルを連鎖させバーストダメージ

✅ Strengths

🎯

集敵能力

聖遺物が敵を引き寄せ、味方に理想的なAoE機会を創出。

⚡

2回の感電付与

聖遺物は展開時と回収時の両方で感電を付与 — 1回で2回の状態異常ヒット。

📈

高い成長余地

チーム編成の最適化に伴い、最もティアランクが上がる可能性のあるヒーロー。

🌀

密集集団スペシャリスト

雑魚敵の多いコンテンツでの集団敵に対してはBティアをはるかに超える性能。

❌ Weaknesses

  • 状況依存 — 単体ボスや散らばった敵には集敵が無意味
  • 個人ダメージは低め — 主にサポート/起点ヒーローでメインDPSではない
  • チーム連携が必要 — 集敵・感電状態を活用できる味方が必要
  • Bティア基準 — 単体コンテンツでは他のヒーローが優れる

🎮 Combat Tips

  1. 展開と回収 — 聖遺物は展開時と回収時の2回感電を付与することを忘れずに。回収タイミングで価値を最大化。
  2. バースト前に集敵 — シオンで先に敵を集め、オルネットや他のAoE DPSに交代
  3. 雑魚敵の多いコンテンツで — シオンは密集敵ステージで真価を発揮。単体ボス戦では他のサポートを検討。
  4. タルテと組ませる — 集団への素早い感電蓄積にタルテが不可欠
  5. 過小評価禁止 — Bティアだが、シオンの集敵は適切なコンテンツでは唯一無二
