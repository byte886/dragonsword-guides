Theresia — 異端審問官

処刑権限を持つわずか10人の異端審問官の1人。ゲーム内で最も自給自足できる出血とスタンのDPS — 両方の状態異常を単独で付与し、セットアップパートナーは不要です。

双槌
アンプリチュード特性
出血 / スタン
交換ショップ
⚡ クイックアンサー

Theresiaはゲーム内最強のアグレッシブキャリーです。出血とスタンの両方を単独で付与するため、チームを編成しやすい最も簡単なヒーローです。コアループ: コンセクレイション (出血) → セレスティアルヴァーディクト (スタン) → Roxyに切り替えてバースト。最強チーム: Theresia + Roxy + Lute。

⚔️ 全スキル解説

スキル タイプ 効果
コンセクレイション (奉献) アクティブ 回転する槌を残す強力な前方打撃。発動時、通常攻撃チェーンを延長。出血を付与。
セレスティアルヴァーディクト (天の裁き) アクティブ ジャンプして地面を叩きつけ、着弾時に衝撃波を発生。スタンを付与。味方のシグナルスキルウィンドウを開く。
ディバインアーク (神の弧) シグナルスキル スタン状態の敵で発動。ターゲットにダッシュして出血を付与。メインバーストスキル — ゲーム内で最もダメージの高いスキルの1つ。
ホーリーライズ (聖なる上昇) シグナルスキル 出血状態の敵で発動。出血を再付与し、ターゲットを浮遊させる。Theresiaを浮遊チームに統合。

🔄 コアコンボループ

Theresia単独セットアップ

ほとんどのヒーローと異なり、Theresiaは状態異常をセットアップするためのパートナーを必要としません。すべてを自分一人で行います：

  1. コンセクレイション — 出血を付与、攻撃チェーンを延長
  2. セレスティアルヴァーディクト — 叩きつけてスタン、シグナルウィンドウを開く
  3. 味方に切り替え — Roxyまたは別のヒーローがスタン状態の敵でシグナルスキルを発動
  4. 切り替えて戻す — スタン状態のターゲットにディバインアークでプレッシャーを継続
💡 重要な洞察

Theresiaは出血とスタンの両方を単独で付与するため、ゲーム内で最も柔軟なチームアンカーです。どちらかの状態異常に反応するヒーローなら誰でも彼女と組めます。

🛡️ 最強ビルド (エンドゲームコンセンサス)

専用カルマ慈悲深き死刑宣告
装備セット3 ルインズブレイカー + 2 ホーリーアービター
メインステータスATKパワーアップ → クリティカルヒット確率 → クリティカルダメージ
サブステータス追加パワー > ATKパワーアップ > DEF無視
ルーンレゾルブ (または最大クリティカルダメージのためにアンプリフィケーション x5)
ステータス目標約80% クリティカル率 / 約150% クリティカルダメージ

このビルドの理由

  • 3-piece ルインズブレイカー — シグナルスキルでDEF無視 (10秒、20% DEF貫通)。ボスダメージに必須。
  • 2-piece ホーリーアービター — スタン状態の敵に+15%ダメージ。Theresiaのスタン重視のプレイスタイルに完全一致。
  • レゾルブ — 信頼できるダメージブースト。最大クリティカルダメージに賭けたい場合はアンプリフィケーション x5に交換。

👥 最強チーム構成

チーム 最適な用途 コアループ
Theresia + Roxy + Lute 最強のオールラウンドチーム Theresiaから出血 + スタン → 制御中にRoxyが出力 → Luteが回復
Theresia + Reina + Castella エンドゲーム最強オールラウンド 現在のエンドゲームベンチマーク。ほぼすべてのアクティビティに対応。
Theresia + Castella + Lute 長いボス戦 Castellaが追加のスタン付与、Luteが持続を提供
Lute + Theresia + Ornette 初心者 初期アンロック、無料装備、バランスの取れた持続 + ダメージ、複雑なメカニクスなし
Theresia + Roxy + Castella 出血特化 高HPターゲットで出血ダメージを最大化。ヒーラーなし — 高スキル。

👹 ボス戦ループ

  1. Theresiaのセレスティアルヴァーディクトで開始してスタンを付与
  2. 敵がスタン状態になったら、Roxyに切り替えてシグナルスキルを発動
  3. ターゲットが制御されている間、Roxyで出力を継続
  4. 3人目のヒーロー (回復のLute、追加スタンのCastella) を使用してループを完了
  5. Theresiaに切り替えて繰り返し — コンセクレイション → セレスティアルヴァーディクト → ディバインアークバースト

🎮 戦闘のコツ

1

自給自足のセットアップ

Theresiaは状態異常をセットアップするために味方を必要としません。出血 + スタンを単独で付与 — 両方を確実に行える唯一のヒーロー。

2

まずコンセクレイション

常にコンセクレイションで開始して出血を付与し、セレスティアルヴァーディクトでスタンする前に攻撃チェーンを延長。

3

ディバインアーク = バースト

スタン状態の敵へのディバインアークがメインダメージソース。ゲーム全体で最もバースト力の高いスキルの1つ。

4

浮遊にはホーリーライズ

ホーリーライズは出血状態の敵を浮遊させる。これを使ってTheresiaを浮遊チーム構成に統合。

5

広い槌の範囲

双槌はほとんどの近接武器よりリーチが広い。グループに対してミスすることは稀で、雑魚敵処理に最適。

6

最初に覚醒

6★覚醒でパッシブと強化スキルがアンロック。その時点でクリティカルステータスラインに投資する価値が出る。

⚠️ よくある間違い

  • 間違った属性のカルマ — 常に彼女の専用カルマ (慈悲深き死刑宣告) を使用、汎用武器ではない
  • 同じセットを5ピース — 決して1つのセットを5ピース使わない。3+2ミックス (ルインズブレイカー + ホーリーアービター) が常に優れている
  • DEF無視を無視 — ルインズブレイカーのDEF無視はボスダメージに必須。スキップしないこと
  • 純DPSの心構え — Theresiaの力は状態異常から来る、素の攻撃からではない。常に出血/スタンを付与し続ける
  • 早期の専用カルマ投資 — TheresiiaがメインDPSであると確信するまで、彼女の専用素材をファームするのは待つ
