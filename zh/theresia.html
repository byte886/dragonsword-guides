Theresia — 异端审判官

仅有的十名拥有处决权的异端审判官之一。游戏中最自给自足的流血和气绝DPS——独自施加两种异常，不需要起手搭档。

双持战锤
振幅特性
流血/气绝
兑换商店
⚡ 快速答案

Theresia是游戏中最佳的进攻核心。她独自施加流血和气绝，是最容易围绕搭建队伍的英雄。核心循环：奉献（流血）→ 神圣裁决（气绝）→ 切到Roxy爆发。最佳队伍：Theresia + Roxy + Lute。

🔄 核心连招循环

Theresia单人起手

与大多数英雄不同，Theresia不需要搭档来起手异常。她自己全部搞定：

  1. 奉献——施加流血，延长攻击链
  2. 神圣裁决——砸地造成气绝，开启Signal窗口
  3. 切换到队友——Roxy或其他英雄对气绝敌人触发其Signal Skill
  4. 切回——用气绝目标上的神圣弧光继续压制
💡 关键洞察

因为Theresia独自施加流血和气绝，她是游戏中最灵活的队伍锚点。任何能响应这两种异常之一的英雄都能与她配合。

🛡️ 最佳配装（终局共识）

专属Karma慈悲的死刑宣告
装备套装3件遗迹破坏者 + 2件圣裁者
主属性攻击力提升 → 暴击率 → 暴击伤害
副属性额外力量 > 攻击力提升 > 防御穿透
符文决意（或5件增幅追求最大暴击伤害）
属性目标约80%暴击率 / 约150%暴击伤害

为何这样配装

  • 3件遗迹破坏者——Signal Skills防御穿透（10秒，20%防御穿透）。Boss伤害的关键。
  • 2件圣裁者——对气绝敌人+15%伤害。完美匹配Theresia侧重气绝的玩法。
  • 决意——可靠的伤害提升。如果想赌最大暴击伤害可换成增幅x5。

👥 最佳队伍搭配

队伍 最适合 核心循环
Theresia + Roxy + Lute 最佳综合队伍 Theresia的流血+气绝 → Roxy在控制期间输出 → Lute治疗
Theresia + Reina + Castella 终局最佳综合 当前终局标杆。几乎适用于所有活动。

Theresia + Roxy + Castella 流血专精 最大化高血量目标的流血伤害。无治疗——高操作要求。

👹 Boss战循环

  1. 用Theresia的神圣裁决起手施加气绝
  2. 敌人气绝后，切到Roxy触发她的Signal Skill
  3. 目标被控制期间用Roxy继续输出
  4. 用第三名英雄（Lute治疗，Castella额外气绝）完成循环
  5. 切回Theresia重复——奉献 → 神圣裁决 → 神圣弧光爆发

🎮 战斗技巧

1

自给自足起手

Theresia不需要队友起手异常。她独自施加流血+气绝——唯一能可靠做到两者的英雄。

2

先奉献

总是先用奉献施加流血并延长攻击链，然后再用神圣裁决造成气绝。

3

神圣弧光=爆发

气绝敌人上的神圣弧光是你的主要伤害来源。整个游戏中爆发最高的技能之一。

4

神圣崛起用于浮空

神圣崛起将流血敌人浮空。用这个让Theresia融入浮空队伍搭配。

5

战锤范围广

双持战锤比大多数近战武器范围更广。对群体几乎不会打空，清杂兵表现极佳。

6

先觉醒

6★觉醒后解锁被动和强化技能。只有那时暴击属性线才值得投资。

⚠️ 常见错误

  • 错误元素Karma——总是用她的专属Karma（慈悲的死刑宣告），不要用通用武器
  • 5件同套装——永远不要用5件同一套装。3+2混搭（遗迹破坏者+圣裁者）总是更好
  • 忽略防御穿透——遗迹破坏者的防御穿透对Boss伤害至关重要。不要跳过
  • 纯DPS心态——Theresia的力量来自异常，而非原始攻击。始终施加流血/气绝
  • 过早投资专属Karma——在确定Theresia是你的主DPS之前，不要刷她的专属材料
