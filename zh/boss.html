Boss攻略

Boss有普通攻击无法打破的厚重动力护甲。填满状态异常槽使其气绝，然后在狭窄窗口内触发Signal Skills。先破甲，再爆发。闪避总是胜过打完一套连招。

📖 阅读时间：约6分钟 👹 剧情+世界Boss 🛡️ 动力护甲系统
⚡ 快速答案

大多数Boss有动力护甲或护盾——先打破它们才能造成真实生命值伤害。填满状态异常槽使其气绝，然后在狭窄窗口内切换英雄进行Signal Skill爆发。最佳全能Boss队：Theresia + Castella + Lute。高护甲Boss用Ornette/Alex + Castella。高生命值Boss用Theresia + Roxy打流血。总是闪避而非打完一套连招。

🛡️ Boss核心机制

  • 精英和Boss有厚重动力护甲，普通攻击无法打破
  • 攻击填满状态异常槽——满时敌人进入状态异常状态（气绝）
  • 状态异常状态打开Signal Skill机会造成巨额伤害
  • 你必须在异常激活的狭窄窗口内切换角色
  • 护盾短时间后再生——保持持续压制

👥 按类型推荐的最佳Boss队伍

Boss类型 推荐队伍 核心循环
通用Boss Theresia + Castella + Lute Theresia输出，Lute破甲+功能，Castella在气绝窗口爆发
高生命值 / 流血 Theresia + Roxy + Castella/Lute 奉献施加流血，天罚增加气绝，Roxy切入，Castella/Lute引爆

📖 教学Boss：兽人战士（Lv.3）

游戏第一个Boss

  • 位置：洞穴中一扇巨门后面
  • 特点：战斗中召唤哥布林的巨型兽人
  • 队友：Johnny在这场战斗中协助你

双条机制（生命值+护盾）

  • 必须持续攻击以打破护盾，才能有效伤害生命值
  • 护盾打破后防御下降，可以高效击败
  • 护盾短时间后充能——不要松懈

战斗技巧

  1. 按Shift闪避翻滚远离Boss攻击
  2. 闪避后向前移动并攻击
  3. Johnny的攻击可以浮空（击飞）Boss
  4. 跳跃攻击浮空的兽人战士
  5. 使用换人连携攻击更快结束

🎯 通用Boss策略

1. 先破甲

  • 大多数Boss有护盾或动力护甲
  • 打破护盾才能造成有效伤害
  • 护盾再生——保持持续压制
  • 破甲英雄：Alex, Ornette, Lute

2. 异常链连招

  • 用主动技能施加状态异常
  • 等待队友头像亮起
  • 在狭窄窗口内切换以触发Signal Skills
  • 重复循环，而非死守一个英雄

3. 闪避 > 连招

  • 绝不要为了打完一套连招而承受伤害
  • Boss攻击有清晰的前摇动画——及时闪避
  • 闪避后重新组织进攻

4. 使用浮空 / 击倒

  • 浮空敌人无法反击
  • 击倒敌人承受更多伤害
  • 注意：超级护甲阻止这些状态——带破甲选项

📋 已知Boss类别

📖

剧情Boss

兽人战士（教学）、龙（序章过场），以及主线任务推进中遇到的其他Boss。

🌍

世界Boss

散布在开放世界各区域。每日刷新。提供升级材料和Karma卡。查看交互地图获取位置。

🗿

雕像Boss

在修复奥尔加纳雕像时触发：废墟神殿（Lv60）、荒芜贸易站（Lv60巨魔）、海鸥村（Lv25野兽）、回声峡谷。

🏰

副本Boss

多人副本Boss。掉落符文和高阶材料。需要协调的团队配合。

🍳 战斗前：准备

  • 挑战Boss前吃煮增益炖菜（15分钟攻击/暴击增益）
  • 至少带一瓶复活茶以防队友倒下
  • 给主DPS装备3件遗迹破坏者获取防御穿透
  • 修复最近的奥尔加纳雕像作为附近的治疗锚点
  • 根据Boss类型匹配队伍（护甲vs生命值vs通用）
