希翁 — 奥加纳化身

女神奥加纳的化身。希翁擅长聚集敌人并施加感电，为队友创造AoE爆发机会。目前B级，但被认为是最有可能随队伍开发而升阶的英雄。

Organa Order
Thunderbolt Trait
Shock / Knockdown
Hybrid Support
⚡ 快速答案

希翁是感电辅助，擅长聚集密集敌群并施加感电，为队友创造AoE爆发窗口。他的圣物在部署和回收时都会造成伤害并施加感电。整体B级，但对抗密集敌人时远超评级。最佳搭档：奥妮特+塔特组成感电队，或与鲁特平衡搭配。

⚡ Combat Style

希翁的核心机制是圣遗物（성물），一个可部署的力场，将敌人聚拢到一起。圣遗物在部署和收回时都会造成伤害并施加感电判定 — 也就是说在正确时机收回，一次使用可以施加两次感电。

这让希翁在对付密集敌群时表现出色：他把敌人聚到一起、施加感电，为奥妮特等 AoE 型队友创造爆发窗口。他的价值高度依赖场景 — 打单体或分散敌人时聚拢能力就浪费了。

⚔️ 最佳配装

感电辅助配装（推荐）

套装

3 件奔雷 + 2 件碎墟（或感电 3+击倒 2）

奔雷提升感电伤害和异常速度。碎墟追加无视防御。备选：专注击倒连锁时用感电 3+击倒 2。

主属性

攻击力提升 → 暴击率 → 暴击伤害

辅助向配装：攻击速度、异常施加率

技能优先级

优先点攻击分支的伤害节点和暴击相关被动。专注核心被动而非长冷却主动技能。

👥 最佳队伍搭配

队伍 适用场景 Sion's Role
Ornette + Tarte + Sion 密集群体 / AoE 关卡 聚拢敌人并施加感电；奥妮特随后 AoE 爆发
Ornette + Lute + Sion Balanced Shock team 铺感电和聚拢；琉特提供治疗和攻击增益
Sion + Tarte + Lute 生存向感电队 聚拢和感电；塔露特和琉特提供续航

奥妮特+塔露特+希翁 — 感电队循环

  1. 希翁部署圣遗物聚拢敌人并施加第一次感电
  2. 塔露特在聚拢的敌群上叠加额外感电减益
  3. 希翁收回圣遗物造成第二次感电和伤害
  4. 奥妮特以大范围镰刀 AoE 切换上场，打击聚拢的感电敌人
  5. 在感电窗口内连锁信号技能打爆发伤害

✅ 优势

🎯

聚拢敌人

圣遗物将敌人拉到一起，为队友创造理想的 AoE 机会。

⚡

双重感电

圣遗物部署和收回时都施加感电 — 一次使用两次异常命中。

📈

高成长潜力

随着队伍搭配被优化，最有可能梯队排名上升的英雄。

🌀

密集群体专家

在杂兵密集的内容中打聚拢敌人时远超 B 梯队水平。

❌ 劣势

  • 依赖场景 — 打单体 Boss 或分散敌人时聚拢无用
  • 个人伤害较低 — 主要是辅助/铺垫英雄，不是主力输出
  • 需要团队配合 — 需要能利用聚拢感电敌人的队友
  • B 梯队基线 — 打单体内容时其他英雄比他强

🎮 战斗技巧

  1. 部署和收回 — 记住圣遗物施加两次感电：部署时和收回时。把握收回时机最大化价值。
  2. 先聚再爆 — 让希翁先聚拢敌人，再切奥妮特或其他 AoE 输出
  3. 用于杂兵密集内容 — 希翁在敌群密集的关卡大放异彩。单体 Boss 战考虑其他辅助。
  4. 搭配塔露特 — 塔露特对于在聚拢敌群上快速叠加感电至关重要
  5. 别低估他 — 虽然是 B 梯队，但希翁的聚拢能力在合适内容中独一无二、不可替代
