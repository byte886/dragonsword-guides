英雄配装

完整配装指南

每个英雄的最佳装备套装、Karma武器、主属性和符文。配装假设：完全觉醒的英雄，非满级Karma或完美副属性。

📖 阅读时间：约10分钟 ⚔️ 16个英雄配装 🔄 2026年8月更新
⚡ 快速配装公式
  1. 先完全觉醒你的英雄（解锁被动和增强套装效果）
  2. 用3件遗迹破坏者作为核心（几乎所有人都需要防御穿透）
  3. 目标约80%暴击率和约150%暴击伤害
  4. 添加匹配你英雄异常的2件元素套装
  5. 队伍：一个英雄施加异常，下一个引爆它

📊 通用属性优先级

🎯

暴击率约80%

你的第一个目标。低于80%会损失太多伤害稳定性。优先在胸甲和腿甲上堆。

💥

暴击伤害约150%

暴击率达标后，堆叠暴击伤害。所有配装的主要伤害乘数。

⚡

副属性优先级

额外力量 > 攻击力提升 > 防御穿透。重铸装备按此顺序刷。

🔥 元素特定配装逻辑

猛毒 / 中毒（Johnny + Charlotte）

  • Johnny——主要猛毒DPS，在场上维持中毒。2件毒雾暗影放大中毒伤害。
  • Charlotte——需要Johnny维持中毒才能达到爆发上限。两者为彼此设计。

烈焰 / 燃烧（Aria + Kalien + Kalsion）

  • Aria——起手者。同时施加燃烧和浮空。Reina和Kalsion的最佳起手英雄。用3件炽焰。
  • Kalien——通过狐狸分身快速叠加燃烧。狐狸抓取和终曲提供爆发+气绝。
  • Kalsion——重击手。武器烈焰增强伤害，但需要浮空和燃烧起手者才能达到巅峰。

冰霜 / 冰冻（Othello + Cerese + Dana）

  • Cerese——最佳冰霜施加者。多段伤害+强力控制分组。弱点：大型Boss（长动画，冰风暴劣势）。
  • Othello——冰霜DPS。需要快速叠冰霜来触发最大伤害窗口。专属Karma弥补低基础暴击被动。
  • Dana——灵活。在场外造成冰霜，用使魔牵制敌人，完美格挡后提供队伍护盾。

流血 / 气绝（Roxy + Theresia + Astria）

  • Roxy——全距离快速叠流血，但需要气绝来最大化伤害。Theresia和Astria是天然搭档。
  • Theresia——场上DPS。同时施加流血和重型气绝。
  • Astria——用机动性换伤害。雨状箭矢叠加气绝和破击。队友控制敌人时输出。暴击率是最高优先级。

疾风 / 浮空（Reina + Eileen）

  • Reina——单体专家。对浮空敌人的长技能连招链。2件苍蓝疾风直接放大疾风伤害。Aria是最佳起手者。
  • Eileen——从进攻角度支援浮空。提升队伍移动速度和攻击力。作为快速切换角色表现良好，暴击扎实。最灵活的装备（生命之歌或遗迹破坏者）。

雷电 / 电击（Ornette）

  • Ornette——强力的雷电英雄，可以领导大多数队伍。在电击队伍中达到巅峰。2件雷霆冲刺是必需的。
  • 当Sion和Tarte不可用时，Lute可作为替代搭档（治疗和攻击力增益维持Ornette的输出）。

🌟 特殊英雄

⚔️

Lute

游戏中仅有的两个治疗者之一（另一个是Tarte）。几乎任何队伍的通用选择。第一个觉醒节点提升队伍攻击力。适合击倒和气绝队伍。2件神圣仲裁者提供治疗输出，遗迹破坏者维持个人伤害。

✨

Tarte

另一个治疗者。配装仍在最终测试中。在生存成为瓶颈的高难度内容中价值显著上升。

🗡️ 专属Karma获取

专属Karma武器（如Johnny的流浪之刃或Cerese的永恒暴风雪）需要残影碎片和记忆来获取。

  • 刷这些材料是功能配装和完全优化配装之间的主要进度门槛
  • 在追求完美符文副属性之前，优先为你计划主修的英雄刷碎片
  • 基础Karma可以在兑换商店购买，不是英雄特定的
  • 用7个相同的基础Karma升满（1个本体+6个副本）
  • 世界Boss可以掉落基础Karma（随机），每日可刷

🤝 队伍搭建原则

💡 关键洞察

大多数DPS英雄需要至少一个特定条件才能达到伤害上限：

  • Reina和Kalsion需要浮空
  • Othello需要冰霜层数
  • Charlotte需要场上中毒
  • Roxy需要气绝

在最终确定队伍之前，确定你的主DPS需要什么，并确保至少一个队友能可靠施加它。
