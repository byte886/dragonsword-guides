核心机制

战斗系统攻略

龙之剑的战斗比看起来更深。掌握三步循环：状态异常 → Signal Skills → 换人连携，释放毁灭性的连招链。

📖 阅读时间：约10分钟 ⚔️ 9种状态异常 🔄 3英雄换人系统
💡 核心理念

普通攻击只填充异常槽。真正的伤害来自Signal Skills，通过在你的三英雄队伍中叠加兼容的状态异常来触发。队伍协同比单个角色强度更重要。

🔄 三步战斗循环

每个成功的连招都遵循这个基本模式：

1️⃣

主动技能

使用主动技能施加第一个状态异常。每个英雄有2个不同属性和效果的主动技能。

2️⃣

Signal Skills

异常触发时，场下英雄头像闪烁。在正确时机切入释放强力Signal Skill，施加下一个异常。

3️⃣

换人连携

在连招窗口内继续切换英雄，连锁换人连携，维持压制并延长链条造成巨额伤害。

⚠️ 重要时机提示

看到英雄头像闪烁并不意味着Signal已就绪。你必须等待实际的状态异常触发，然后在狭窄窗口内切换。过早切换会浪费Signal机会。

🩸 全部9种状态异常详解

每个英雄施加一种或多种状态异常。叠加兼容类型是触发Signal Skills的关键。

⚡ Signal Skills深度解析

Signal Skills是游戏中最强的攻击。以下是它们的工作原理：

如何触发

  1. 攻击敌人填充他们的异常槽
  2. 槽满时，敌人进入状态异常状态
  3. 能响应该异常的场下英雄头像会闪烁
  4. 按该英雄的切换按钮——他们以特殊Signal Skill攻击入场
  5. Signal Skill造成高伤害并施加下一个异常

关键特征

  • 每个英雄有2个Signal能力（除了2个主动技能）
  • Signal Skills仅在敌人处于兼容异常状态时可用
  • 场上英雄和等待英雄都可以激活Signal Skills
  • 伤害公式围绕通过角色切换连锁这些技能展开
  • 有效连接主动和Signal技能是战斗的全部核心

🔀 换人连携与连招连锁

战斗的真正深度在于将多个英雄连锁在一起：

无限异常链

当三个英雄都维持不同的异常覆盖时，你可以创造不间断的状态链：

  1. 英雄A施加气绝 → 触发英雄B的Signal Skill
  2. 英雄B以Signal Skill入场，施加流血 → 触发英雄C的Signal Skill
  3. 英雄C以Signal Skill入场，施加浮空 → 触发英雄A的Signal Skill
  4. 英雄A重新入场，再次施加气绝 → 循环重复

切换还会提供短暂的无敌帧（i-frames）直到你的下一次攻击，使其兼具进攻和防御性。

👥 三个队伍定位

每个成功的队伍搭配都填补这三个位置。这些是连招中的定位，而非永久职业：

🎯

场上驱动者

保持在场上活跃，创造下一个可重复条件。让连招持续的队伍"引擎"。

⚡

Signal响应者

条件亮起时入场。造成大额Signal Skill伤害并施加链中的下一个异常。

🌉

桥梁

延长压制或恢复间距，然后交还战斗。在大额伤害窗口之间维持链条。

🪽 浮空连招队伍

浮空是最强机制之一，因为被击飞的敌人无法反击或触发防御格挡。

🏆 顶级浮空队伍

Reina + Theresia + Roxy

  • Reina是主要击飞者，保持敌人浮空
  • Theresia处理空中连招伤害
  • Roxy延长链条

备选：Reina + Castella + Lute/Aria

⚠️ 超级护甲注意事项

当敌人激活超级护甲时，他们无法被击飞或击倒。浮空队伍对这些敌人失去大量价值——总是准备好破甲选项。

🎮 如何练习战斗

  1. 从简单开始——找一个耐打的敌人，练习施加一个状态异常，等待Signal提示，然后切换一次
  2. 加入第三个英雄——两步响应感觉可靠后，引入第三个英雄完成完整链条
  3. Boss练习——Boss遵循相同序列：确定安全起手，预留后续攻击，需要闪避时中断链条
  4. 闪避优先——总是优先闪避而非完成连招。死亡的英雄造成零伤害。

📜 六大核心战斗原则

1

异常是核心

普通攻击只填充槽。真正的伤害来自异常触发的Signal Skills。

2

协同 > 伤害

三个强力英雄不等于强力队伍。互补的异常才能赢。

3

时机就是一切

在狭窄的异常窗口内切换。过早切换浪费Signal机会。

4

闪避优先

永远不要用连招换你将承受的伤害。先生存，再优化。

5

匹配敌人

Boss需要持续伤害和破甲。开放世界需要机动性和控制。

6

带破甲

超级护甲阻挡击飞/击倒。总是在后备中准备破甲者。
