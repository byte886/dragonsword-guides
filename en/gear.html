Progression System

Gear & Equipment Guide

Gear defines your hero's role through set bonuses. The golden rule: 3 pieces of one set + 2 of another. Set bonuses matter more than rarity. Most gear is crafted at the Blacksmith, not dropped.

📖 Reading time: ~7 min 🛡️ 9+ Armor Sets ⚒️ Craft > Drop
⚡ Quick Answer

Always use 3+2 set mixing (3 of one set + 2 of another), never 5 of the same set. Set bonuses > rarity — a high-rarity piece that breaks your 3+2 is a downgrade. Craft gear at the Blacksmith matching your hero's element. Use Forging Molds to pick the main stat on chest pieces. Reforging is late-game optimization, don't rush it.

🎯 The 3+2 Set Bonus Principle

This is the most important gear rule in the game:

Gear Choice Result
3-pc Set A + 2-pc Set B Activates 3-piece effect (defines role) + 2-piece effect (secondary bonus). Recommended.
5-pc same set Keeps 3-piece effect but wastes 2 slots that could activate another bonus.
Random high-rarity pieces May have better raw stats but disables set bonuses your build relies on.
⚠️ Critical

Set bonuses are the FIRST thing to check before rarity. A useful build is almost always 3 of one set + 2 of another. A high-rarity drop can be a downgrade if replacing a slot breaks your 3+2 configuration — the set bonus loss may outweigh the item color or level gain.

🔄 Gear Progression Loop

System Purpose
Dungeons Unlock stronger stages as story progresses. Farm higher-tier gear.
Merc Guide / Special Challenges Check which dungeon drops the set pieces you need.
Currency Dungeons Farm ores, gold, XP books, Karma cards and higher upgrade materials.
Raids Once gear level supports rune slots, farm runes and related resources.
Upgrades Spend ores and gold to raise gear to current level cap.
Reforging Use Shape Grinder on max-level gear to reroll substats. Locking substats costs more gold.

📈 Gear Levels

  • Low-tier gear has low level caps and fewer substats
  • High-tier gear has large upgrade space, can reach level 15
  • As you unlock more dungeons through the story, the same sets get stronger tier versions
  • Basic sets from normal dungeons: Battle Will, Ballad of Life, Intruder
  • More niche sets come from crafting

📊 Main Stats vs Substats

Good gear isn't just high-level gear — it has the right stats for your hero's role:

  • A Frost DPS hero gets very little value from Bleed substats (unless the team actually uses Bleed)
  • Stun, Knockdown, Airborne, Break-focused heroes need stats that nurture that function
  • Survival stats matter most for heroes who actually take pressure or need uptime for Signal setups
  • Chest slot is especially important — it carries the strongest main stat values on armor
  • Use Forging Mold when crafting to choose the desired main stat instead of accepting random

Substat Priority (DPS)

  1. Critical Damage
  2. Attack Power
  3. Defense Ignore
  4. Airborne Damage

⚒️ Crafting System (Blacksmith)

Most gear is crafted at the Blacksmith, not dropped by enemies.

Material Sources

  • Clear Trait Dungeons for trait stones
  • Buy with Adventurer's Emblem medals at the Exchange
  • Craft at Alchemist NPC Shanoa
  • Decompose unwanted gear for materials
  • Low-tier materials can be synthesized into higher-tier at the alchemist

Crafting Rules

  • Each hero specializes in one element — always craft gear matching the hero's element
  • Select the main stat before confirming the craft
  • Use Forging Molds to customize the main stat

🔧 Forging Molds

  • Obtained through daily regional quests
  • Allow you to choose the main stat of the created item instead of random
  • Especially important for crafting gear for your main team
  • Don't waste good molds on temporary low-tier gear — save them for high-tier equipment

🔨 Reforging System

If crafted gear has undesirable substats, you can improve them through reforging at the Blacksmith:

  • Requires Stat Grinder material (purchasable for 25 Adventurer's Emblem medals each) + gold
  • Results are random — treat it as a gradual optimization tool, not something to farm aggressively early
  • Locking substats during reforge costs more gold
  • Best viewed as a long-term investment, not an early-game goal

📜 Gear System Core Principles

1

3+2 > 5-Piece

Mixing two sets is almost always stronger than a pure 5-piece. Two bonuses beat one.

2

Sets > Rarity

Check set count first, then equip. A rare piece that breaks 3+2 is a downgrade.

3

Match Element

Always craft gear matching your hero's element. Mismatched elements waste bonuses.

4

Chest = Most Important

Chest slot carries the strongest main stat. Use Forging Molds to customize it.

5

Reforge Late

Reforging is random and expensive. Don't invest early — wait for endgame gear.

6

Craft > Drop

Most gear comes from Blacksmith crafting. Materials from dungeons and decomposition.
