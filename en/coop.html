Co-op Guide

DragonSword: Awakening supports limited co-op through Hunts (2 players) and Raids (3 players). No open-world or story co-op. Join via invite code — no matchmaking, no friend list required. Each player brings their own full 3-hero party.

📖 Reading time: ~5 min 👥 Hunts 2P / Raids 3P 🔗 Invite Code Only
⚡ Quick Answer

Only Hunts (2P) and Raids (3P) support co-op. No open world, no story, no Tower of Trials multiplayer. Every session requires creating a lobby and sharing an invite code. No matchmaking — only friends via code. Each player uses their own 3-hero party. No quick retry — must recreate lobby after each run. The game is primarily a single-player experience.

✅ Co-op Supported Content

Mode Max Players Description
Hunts (Subjugation) 2 players Closed-arena boss battles. Each player brings their own 3-hero party.
Raids 3 players High-difficulty instanced content. Can be played solo or with up to 2 friends.

❌ No Co-op Content

  • Main story — Campaign is single-player only
  • Open world exploration — Cannot explore the map together
  • Tower of Trials — Endgame challenge is solo only
  • General field exploration — No overworld co-op
  • Side quests — All quests are single-player
  • PvP — No player vs player mode exists

🎮 How to Play Co-op

  1. Host creates a lobby — Open the multiplayer menu and create a new session
  2. Select content & difficulty — Only the host can choose Hunt/Raid and difficulty level
  3. Generate invite code — The lobby produces a unique invite code
  4. Share the code — Send the invite code to your friend(s)
  5. Friends enter code — Friends input the invite code to join the lobby
  6. Start battle — Once everyone is ready, begin the encounter
  7. Lobby disbands after — Must recreate the entire lobby for another run

⚙️ Co-op Mechanics

🔗

Invite Code System

Join via unique invite code. No Steam friend list required. No matchmaking — you can only play with people who have your code.

👥

Each Player = Full Party

Every player brings their own complete 3-hero party. In a 3-player raid, that's 9 heroes on the field simultaneously.

🏠

Host Controls Everything

Only the lobby host selects content and difficulty. If settings are wrong, the entire lobby must be disbanded and recreated.

🔄

No Quick Retry

After completing a Hunt or Raid, the lobby disbands automatically. You must go through the full lobby creation process again for another run.

👍 Advantages of Co-op

  • Easier high-difficulty content — Raids and high-tier Hunts are much more manageable with friends
  • Social experience — Tackle bosses together and share the challenge
  • Full party per player — Each player has 3 heroes, creating rich tactical combinations
  • Simple invite system — No friend list needed, just share a code
  • Raids can be solo or co-op — Choose based on your preference and party strength

👎 Limitations & Issues

  • Very limited content — Only Hunts and Raids. No open-world co-op at all
  • Cumbersome workflow — Must recreate lobby after every run, no quick retry
  • Host-only settings — Only the host picks content/difficulty; wrong setup means full restart
  • No matchmaking — Can't play with random players, friends only
  • Guest progress unclear — Whether guest progress saves is not fully documented
  • Unlock conditions unclear — Exactly when multiplayer unlocks is not well documented
  • Mod conflicts — Mods may prevent online play (both players need identical mods or bypass patches)

💡 Co-op Tips

1

Coordinate Parties

Talk with friends about team composition beforehand. Cover different elements and roles (DPS, support, breaker) for maximum efficiency.

2

Host Plans Ahead

As host, know exactly which Hunt/Raid and difficulty you want before creating the lobby. Wrong settings = full restart.

3

Bring Buff Food

Each player should eat their own Boiling buff stews before joining. 15-minute ATK/Crit buffs stack across the party.

4

Use for Endgame Only

Co-op is really only useful for high-difficulty Raids and Hunts. The story and open world are designed for solo play.
